13:T2b48,<h1>■はじめに</h1>
<p>データを永続的に保存する方法で、数々の方法があります。
以下に一例を挙げます。
・UserDefaults
・CoreData
・SQLite
・Realm</p>
<p>ここでは、「Realm」に関して記載します。</p>
<h1>◾️Realm（レルム）とは</h1>
<p>Realm（レルム）とは、クロスプラットフォームに対応しているデータベースです。（Mobileデータベース）</p>
<p>SQLiteやCoreDataなどと比べて、速度が早い（性能がいい）、実装が容易などの利点があります。
また、無料で利用できるのも大きなメリットです。</p>
<p>Realmには、以下の種類がありますが、ここでは「Realm Database」に関して記載します。</p>
<p>【Realm Database】
・オフラインで利用できるデータベースサービス（SQLiteやCoreDataと同様のサービス）</p>
<p>【Realm Platform】
・「Realm Database」で管理するデータをクラウドでマルチデバイスに同期する事ができるmBaaSサービス</p>
<p>【Realm Studio】
・「Realm Platform」のデータを操作（参照、削除など）する事ができる開発ツール</p>
<h1>◾️Realmのインストール</h1>
<p>RealmのインストールにはCocoaPodsを使用できます。
※CocoaPodsに関しては記載を省きます。</p>
<p>以下のPodを追加する事でインストールを行う事ができます。</p>
<pre><code>pod 'RealmSwift'
</code></pre>
<h1>◾️Realmのテーブルの作成</h1>
<p>「Realmのテーブルの作成」と書きましたが、Realmにはテーブルという概念がありません。
では、どのようにデータを登録するのかですが、登録するObjectをまとめたクラスを作成します。
このクラスが、SQLでいう所のテーブルになります。</p>
<p>具体的には、以下のようなクラスを作成します。
※例では、String型とInt型のみ記載していますが、他の型も定義可能です。</p>
<pre><code class="hljs language-swift"><span class="hljs-keyword">import</span> RealmSwift

<span class="hljs-keyword">class</span> <span class="hljs-title class_">TargetData</span>: <span class="hljs-title class_ inherited__">Object</span> {
    <span class="hljs-keyword">@objc</span> <span class="hljs-keyword">dynamic</span> <span class="hljs-keyword">var</span> name: <span class="hljs-type">String</span> <span class="hljs-operator">=</span> <span class="hljs-string">""</span>
    <span class="hljs-keyword">@objc</span> <span class="hljs-keyword">dynamic</span> <span class="hljs-keyword">var</span> age: <span class="hljs-type">Int</span> <span class="hljs-operator">=</span> <span class="hljs-number">0</span>
    <span class="hljs-keyword">@objc</span> <span class="hljs-keyword">dynamic</span> <span class="hljs-keyword">var</span> tag: <span class="hljs-type">String</span> <span class="hljs-operator">=</span> <span class="hljs-string">""</span>
}
</code></pre>
<h1>◾️データの登録（CREATE）</h1>
<p>「Realmのテーブルの作成」で作成したクラス（以降は「オブジェクトクラス」と記載する。）に対して、実際にデータを登録する方法を記載します。
※Javaなどを触った事がある人は、イメージが付きますかね？Beanのような使い方になります。</p>
<p>登録する方法は以下です。
※登録処理を記載するクラスでは「RealmSwift」をインポートするようにしてください。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// Realmのインスタンスを生成</span>
<span class="hljs-keyword">let</span> realm <span class="hljs-operator">=</span> <span class="hljs-keyword">try!</span> <span class="hljs-type">Realm</span>()

<span class="hljs-comment">// 登録するオブジェクトクラスのインスタンス生成、パラメータへのデータの代入</span>
<span class="hljs-keyword">let</span> tgt <span class="hljs-operator">=</span> <span class="hljs-type">TargetData</span>()
tgt.name <span class="hljs-operator">=</span> <span class="hljs-string">"あいうえお"</span>
tgt.age <span class="hljs-operator">=</span> <span class="hljs-number">19</span>
tgt.tag <span class="hljs-operator">=</span> <span class="hljs-string">"AAAA"</span>

<span class="hljs-comment">// 書き込みを行う</span>
<span class="hljs-keyword">try!</span> realm.write() {
    realm.add(tgt)
}
</code></pre>
<h1>◾️データの取得（READ）</h1>
<p>「データの登録（CREATE）」で作成したデータを取得する方法を記載します。</p>
<p>取得する方法は以下です。
※取得処理を記載するクラスでは「RealmSwift」をインポートするようにしてください。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// Realmのインスタンスを生成</span>

</code></pre>
<p>SQLを使用した事がある人はイメージがつくかもしれませんが、条件を絞ってデータを取得したい場合もあります。
その場合には、以下のように記載します。
※例では、いくつかのパターンを記載します。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// Realmのインスタンスを生成</span>

<span class="hljs-comment">// 部分一致（nameカラムに 'あ' の文字列を含むレコードを全件取得）</span>
realm.objects(<span class="hljs-type">TargetData</span>.<span class="hljs-keyword">self</span>).filter(<span class="hljs-string">"name contains 'あ'"</span>)
</code></pre>
<p>取得したデータから、必要なオブジェクトを取得して以降の処理で使用したい場合には、以下のような使い方ができる。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// Realmのインスタンスを生成</span>
<span class="hljs-keyword">let</span> realm <span class="hljs-operator">=</span> <span class="hljs-keyword">try!</span> <span class="hljs-type">Realm</span>()

    <span class="hljs-built_in">print</span>(target.name)
