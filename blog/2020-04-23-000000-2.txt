13:T1fab,<h2>■はじめに</h2>
<p>アプリケーションを作成している時に、データを永続的に保存したい場合など、良くありますよね？
※私はよくあります！！</p>
<p>そんな時に、いくつかデータを保存する方法があります。
その中でも今回は、「UserDefaults」について記載します。
（他にも、「CoreData」「SQLite」「NSKeyedArchiver」などありますが、ここでは説明を省きます。）</p>
<h2>■UserDefaults</h2>
<p>UserDefaultsは、データをplistファイルに保存する事でデータを永続的に保持する方法です。</p>
<p>データを保存する時には一旦データをメモリに保存した後に、非同期でplistファイルへ保存します。
アプリケーションの起動時には、plistファイルのデータを全てメモリ上に展開されます。</p>
<p>上記にも記載した通り、plistファイルのデータを全てメモリ上に展開されるため、データ量が多いと
メモリが足りなくなり、アプリケーションが強制終了する原因となります。
そのため、大量のデータを保存することには向いておらず、アプリケーション内の設定や、ユーザー情報などの
限られた情報のみを保存する用途で使用することをお勧めします。
※大量のデータを保存する時には、「CoreData」などを使用してください。</p>
<p>ちなみに、保存できる件数ですが、特に決まりはありません。
メモリが足りる限り保存できるみたいです。。。</p>
<p>【Appleの公式リファレンス】</p>
<p><a href="https://developer.apple.com/documentation/foundation/userdefaults">https://developer.apple.com/documentation/foundation/userdefaults</a></p>
<p>UserDefaultsの具体的な使用方法は以下に記載します。
※NSUserDefaultsではなく、UserDefaultsの使用方法です。
※Swift3.0から「NSUserDefaults」が「UserDefaults」に変わりました。</p>
<h2>◾️インスタンスの生成</h2>
<p>UserDefaultsのインスタンスの生成方法は以下です。
このインスタンスを元にデータの保存や取得などの処理を行います。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// インスタンスの生成</span>
<span class="hljs-keyword">let</span> userDefaults <span class="hljs-operator">=</span> <span class="hljs-type">UserDefaults</span>.standard
</code></pre>
<h2>◾️データの保存（書き込み）</h2>
<p>UserDefaultsのデータの保存方法は以下です。</p>
<p>特定の「Key」に対して、値を保存する形になります。</p>
<pre><code class="hljs language-swift">[<span class="hljs-type">UserDefaultsのインスタンス</span>].set([設定する値], forKey: [設定する値のキー])
</code></pre>
<p>具体的な使用方法は以下です。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// インスタンスの生成</span>
<span class="hljs-keyword">let</span> userDefaults <span class="hljs-operator">=</span> <span class="hljs-type">UserDefaults</span>.standard

<span class="hljs-comment">// String型のデータの保存</span>
userDefaults.set(<span class="hljs-string">"TEST"</span>, forKey: <span class="hljs-string">"Key"</span>)
<span class="hljs-comment">// Bool型のデータの保存</span>
userDefaults.set(<span class="hljs-literal">true</span>, forKey: <span class="hljs-string">"Key"</span>)
<span class="hljs-comment">// Int型のデータの保存</span>
userDefaults.set(<span class="hljs-number">1</span>, forKey: <span class="hljs-string">"Key"</span>)
</code></pre>
<h2>◾️データの取得（読み込み）</h2>
<p>UserDefaultsのデータの取得方法は以下です。</p>
<p>データの保存時に設定した特定の「Key」の値を取得します。</p>
<pre><code class="hljs language-swift">[<span class="hljs-type">UserDefaultsのインスタンス</span>].[型](forKey: [設定する値のキー])
</code></pre>
<p>具体的な使用方法は以下です。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// インスタンスの生成</span>
<span class="hljs-keyword">let</span> userDefaults <span class="hljs-operator">=</span> <span class="hljs-type">UserDefaults</span>.standard

<span class="hljs-comment">// String型のデータの取得</span>
userDefaults.string(forKey: <span class="hljs-string">"Key"</span>)
<span class="hljs-comment">// Bool型のデータの取得</span>
userDefaults.bool(forKey: <span class="hljs-string">"Key"</span>)
<span class="hljs-comment">// Int型のデータの取得</span>
userDefaults.integer(forKey: <span class="hljs-string">"Key"</span>)
</code></pre>
<h2>◾️データの削除</h2>
<p>UserDefaultsのデータの削除方法は以下です。</p>
<p>データの保存時に設定した特定の「Key」の値を削除します。</p>
<pre><code class="hljs language-swift">[<span class="hljs-type">UserDefaultsのインスタンス</span>]. removeObject(forKey: [設定する値のキー])
</code></pre>
<p>具体的な使用方法は以下です。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// インスタンスの生成</span>
<span class="hljs-keyword">let</span> userDefaults <span class="hljs-operator">=</span> <span class="hljs-type">UserDefaults</span>.standard

<span class="hljs-comment">// 型に限らずデータの削除</span>
userDefaults.removeObject(forKey: <span class="hljs-string">"Key"</span>)
</code></pre>
<h2>◾️データの存在確認</h2>
<p>UserDefaultsのデータの存在確認方法は以下です。</p>
<p>データの保存時に設定した特定の「Key」のデータの存在を確認します。</p>
<pre><code class="hljs language-swift"><span class="hljs-keyword">if</span> [<span class="hljs-type">UserDefaultsのインスタンス</span>].object(forKey: [設定する値のキー]) <span class="hljs-operator">!=</span> <span class="hljs-literal">nil</span> {
    <span class="hljs-comment">// データがある場合はこちらの処理</span>

    <span class="hljs-comment">// データがない場合はこちらの処理</span>
 }
</code></pre>
<p>具体的な使用方法は以下です。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// インスタンスの生成</span>
<span class="hljs-keyword">let</span> userDefaults <span class="hljs-operator">=</span> <span class="hljs-type">UserDefaults</span>.standard

<h2>◾️データの同期</h2>
<p>UserDefaultsのデータの同期方法は以下です。</p>
<p>このデータの同期を行わないと、データの保存、データの削除が反映されない場合があります。
※UserDefaultsはデータを非同期でplistに反映するため。。。
※基本的には、データの保存、削除の時にはすぐ後にこの処理を入れておいた方が安全です。</p>
<pre><code class="hljs language-swift">[<span class="hljs-type">UserDefaultsのインスタンス</span>].synchronize()
</code></pre>

<pre><code class="hljs language-swift"><span class="hljs-comment">// インスタンスの生成</span>
<span class="hljs-keyword">let</span> userDefaults <span class="hljs-operator">=</span> <span class="hljs-type">UserDefaults</span>.standard

<span class="hljs-comment">// データの同期</span>
