13:T1d00,<h2>■はじめに</h2>
<p>UserDefaultsを使用していると、物足りなくなってきませんか？
objective-cでは、簡単に保存できていた配列などがSwiftでは一手間が必要になります。</p>
<p>Swiftで配列などの複雑な型をUserDefaultsに保存する方法として色々方法はありますが、ここでは
UserDefaultsを拡張（extension）して保存、取得する方法を記載します。</p>
<h2>◾️String配列</h2>
<p>String型の配列を保存、取得が出来るように拡張します。
他の方の配列を保存、取得したい場合には、型を書き換えるだけです！</p>
<p>拡張方法は、以下です。</p>
<pre><code class="hljs language-swift"><span class="hljs-keyword">extension</span> <span class="hljs-title class_">UserDefaults</span> {
    <span class="hljs-comment">/**
     * UserDefaultsに配列を設定できる様に拡張
     *
     * @param targetArray [String] 設定するString型配列を渡す
     * @param key String Userdefaultsのキーを渡す
     */</span>
    <span class="hljs-keyword">func</span> <span class="hljs-title function_">setHairetu</span>(<span class="hljs-keyword">_</span> <span class="hljs-params">targetArray</span>: [<span class="hljs-type">String</span>], <span class="hljs-keyword">_</span> <span class="hljs-params">key</span>: <span class="hljs-type">String</span>) {
        <span class="hljs-keyword">set</span>(targetArray, forKey: key)
    }

    <span class="hljs-comment">/**
     * UserDefaultsから配列を取得できる様に拡張
     *
     * @param key String Userdefaultsのキーを渡す
     * @return [String]? 対象のキーにString型配列がある場合には、その配列を返す。
     * ない場合には、nilを返す。
     */</span>
    <span class="hljs-keyword">func</span> <span class="hljs-title function_">getHairetu</span>(<span class="hljs-keyword">_</span> <span class="hljs-params">key</span>: <span class="hljs-type">String</span>) -> [<span class="hljs-type">String</span>]<span class="hljs-operator">?</span> {
        <span class="hljs-keyword">guard</span> <span class="hljs-keyword">let</span> areas <span class="hljs-operator">=</span> object(forKey: key) <span class="hljs-keyword">as?</span> [<span class="hljs-type">String</span>] <span class="hljs-keyword">else</span> { <span class="hljs-keyword">return</span> <span class="hljs-literal">nil</span> }
        <span class="hljs-keyword">return</span> areas
    }
}
</code></pre>
<p>実際に、保存、取得する方法は以下です。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// 配列を保存する方法</span>
<span class="hljs-keyword">let</span> hairetu <span class="hljs-operator">=</span> [<span class="hljs-string">"1"</span>, <span class="hljs-string">"2"</span>]

<p>すごく簡単ですね！
一度拡張してしまえば、以降はこのように簡単に使用できるのでオススメです。</p>
