13:Tcfa,<h1>◾️はじめに</h1>
<p>アプリを開発していると、データベースから取得したデータを元に、UIButtonを生成する場合など動的にUIButtonを生成する事がある。
UIButtonをソースコードで動的に生成する場合、ボタン押下時の処理でSelectorの指定が必要になるが、そのSelectorには引数を渡すような機能がない。</p>
<p>そこで、ここでは、Selectorで引数を渡すための方法を記載する。</p>
<h1>◾️Selectorの引数</h1>
<p>まずは、UIButtonのカスタムクラスを作成する。（以下ではCustomButtonとしている。）
カスタムクラスには、UIButtonを継承している必要があります。</p>
<p>このカスタムクラスに引数として使用するための変数を用意します。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// ボタンのカスタムクラス（ボタン押下時のSelectorの引数を使用する為に用意）</span>
<span class="hljs-keyword">class</span> <span class="hljs-title class_">CustomButton</span>:<span class="hljs-title class_ inherited__">UIButton</span> {
    <span class="hljs-comment">// 引数として使用する</span>
    <span class="hljs-keyword">var</span> argument:<span class="hljs-type">String</span>?
}
</code></pre>
<p>上記のカスタムクラスを使用して、UIButtonを生成する。
（以降では、カスタムクラスを使用して生成されたボタンを「カスタムボタン」と記載する。）</p>
<p>カスタムボタンの押下時に引数を渡すために、上記で用意した引数の変数に値を設定した後で
Selectorを使用してボタン押下時の処理を記載する。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// カスタムクラスを使用して、UIButtonを生成する</span>
<span class="hljs-keyword">let</span> button <span class="hljs-operator">=</span> <span class="hljs-type">CustomButton</span>()
<span class="hljs-operator">「</span>button<span class="hljs-operator">」</span>押下時にselector内のメソッド実行
button.argument <span class="hljs-operator">=</span> <span class="hljs-string">"引数の値"</span>
button.addTarget(<span class="hljs-keyword">self</span>, action: <span class="hljs-keyword">#selector</span>(target(<span class="hljs-keyword">_</span>:)), for: .touchDown)
</code></pre>
<p>Selectorで指定されたメソッドにて、渡ってきた引数を確認する場合には、以下の様に記載する。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// 対象のボタン押下時の処理</span>
<span class="hljs-keyword">@objc</span> <span class="hljs-keyword">func</span> <span class="hljs-title function_">target</span>(<span class="hljs-keyword">_</span> <span class="hljs-params">sender</span>: <span class="hljs-type">CustomButton</span>) {
    <span class="hljs-built_in">print</span>(sender.argument)
}
</code></pre>
<p>これで、複数引数を渡したい場合や、String以外の型の引数を渡す事も可能です。</p>
