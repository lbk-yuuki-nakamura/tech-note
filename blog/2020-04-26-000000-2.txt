13:Tb14,<h1>◾️はじめに</h1>
<p>「NSUserDefaults」を使用して、データの保存などを行う際に、リスト形式のデータをそのまま</p>
<p>使用したい場合がある。</p>
<p>ここでは、「NSUserDefaults」に「NSMutableArray」を格納、取得を行う方法を記載する。</p>
<h1>◾️NSUserDefaultsにNSMutableArrayを格納する</h1>
<p>「NSUserDefaults」に「NSMutableArray」を格納するには、そのままでは格納ができない。</p>
<p>その為、一旦「NSData」に変換してから格納する。</p>
<p>具体的には、以下の様に設定する。
（以下では、「NSMutableArray」に値を設定していないが、設定しても同様です。）</p>
<pre><code class="hljs language-objectivec"><span class="hljs-comment">// NSUserDefaultsのインスタンスを生成する</span>
<span class="hljs-built_in">NSUserDefaults</span> *ud = [<span class="hljs-built_in">NSUserDefaults</span> standardUserDefaults];
<span class="hljs-comment">// NSUserDefaultsに格納するNSMutableArrayのインスタンスを生成する</span>
<span class="hljs-built_in">NSMutableArray</span> *array = [[<span class="hljs-built_in">NSMutableArray</span> alloc] init];
<span class="hljs-comment">// NSMutableArrayをNSData型に変換する</span>
<span class="hljs-built_in">NSData</span> *data = [<span class="hljs-built_in">NSKeyedArchiver</span> archivedDataWithRootObject:array];
<span class="hljs-comment">// NSUserDefaultsに値を設定する</span>
[ud setObject:data forKey:<span class="hljs-string">@"TargetKey"</span>];
<span class="hljs-comment">// 設定を反映する</span>
[ud synchronize];
</code></pre>
<h1>◾️ NSUserDefaultsからNSMutableArrayを取得する</h1>
<p>「NSUserDefaultsにNSMutableArrayを格納する」で記載した通り、「NSMutableArray」を</p>
<p>「NSUserDefaults」に格納するために、「NSData」型に変換した。</p>
<p>そのため、取得する際には、「NSData」型から「NSMutableArray」に変換する必要がある。</p>
<p>具体的には、以下の様に取得する。</p>
<pre><code class="hljs language-objectivec"><span class="hljs-comment">// NSUserDefaultsのインスタンスを生成する</span>
<span class="hljs-built_in">NSUserDefaults</span> *ud = [<span class="hljs-built_in">NSUserDefaults</span> standardUserDefaults];
<span class="hljs-comment">// NSUserDefaultsからNSData型の値を取得する</span>
<span class="hljs-built_in">NSData</span> *data = [ud objectForKey:<span class="hljs-string">@"TargetKey"</span>];
<span class="hljs-comment">// NSData型からNSMutableArray型へ変換する</span>
<span class="hljs-built_in">NSMutableArray</span> *array = [<span class="hljs-built_in">NSKeyedUnarchiver</span> unarchiveObjectWithData:data];
