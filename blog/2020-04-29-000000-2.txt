13:Tcd8,<h2>■はじめに</h2>
<p>この環境構築はmacを前提にしています。</p>
<h2>■手順</h2>
<p>1.AppStoreで「Xcode」をインストールする。（Xcodeの中に入っている「Command Line Tools」が必要になります。）</p>
<p><img src="/images/2020-04-29-000000-2/20220707130331.png" alt=""></p>
<p>2.「1」でインストールしたXcodeを開き、以下の画面まで進める。（インストールなど実施する。）</p>
<p><img src="/images/2020-04-29-000000-2/20220707120746.png" alt=""></p>
<p>2.以下のURLにアクセスし、Homebrewのインストールコマンドをコピーしてターミナルに貼り付け、実行する。</p>
<p><a href="https://brew.sh/index_ja">https://brew.sh/index_ja</a></p>
<p><img src="/images/2020-04-29-000000-2/20220707130359.png" alt=""></p>
<p>3.以下のコマンドをターミナルで実行し、nodebrewをインストールする。</p>
<pre><code>$ brew install nodebrew
</code></pre>
<p>4.以下のコマンドをターミナルで実行し、nodebrewをセットアップする。</p>
<pre><code>$ nodebrew setup
</code></pre>
<p>5.以下のコマンドをターミナルで実行し、設定を行う。</p>
<p>※「.bashrc」の部分は「.bash_profile」に書き換えても可（自身の環境に合わせて変えてください。</p>
<p>※新しいmacを利用している人は、「bash」ではなく、「zsh」に変更されていますので、「.bashrc」の部分は「.zprofile」に書き換えてください。</p>
<pre><code>$ echo 'export PATH=$HOME/.nodebrew/current/bin:$PATH' >> ~/.bashrc
</code></pre>
<p>6.以下のコマンドを実行して、「6」で設定したPATHを反映させる。</p>
<p>※「.bashrc」の部分は「.bash_profile」に書き換えても可（自身の環境に合わせて変えてください。</p>
<p>※新しいmacを利用している人は、「bash」ではなく、「zsh」に変更されていますので、「.bashrc」の部分は「.zprofile」に書き換えてください。</p>
<pre><code>$ source ~/.bashrc
</code></pre>
<p>7.以下のコマンドを実行して、Node.jsの安定版のインストールする。</p>
<pre><code>$ nodebrew install stable
</code></pre>
<p>8.以下のコマンドを実行して、Node.jsの「安定版」を利用するように反映する。</p>
<pre><code>$ nodebrew use stable
</code></pre>
<h2>■おまけ</h2>
<p>以下のコマンドで、インストールできるNode.jsのバージョンが確認できます。</p>
<pre><code>$ nodebrew ls-remote
</code></pre>
<p>上記で確認したバージョンを以下のようにコマンド実行することで、指定バージョンをインストールすることができます。（以下は「v12.5.0」をインストールする場合）</p>
<pre><code>$ nodebrew install-binary v12.5.0
</code></pre>
<p>インストールしたら、バージョンを切り替える必要がありますので、以下のコマンドでバージョンを切り替えましょう。</p>
<pre><code>$ nodebrew use v12.5.0
</code></pre>
<p>ちなみに、インストールしているNode.jsの全てのバージョンを確認したい場合は以下のコマンドです。</p>
