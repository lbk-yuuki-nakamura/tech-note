<ul>
<li>VPSを契約する。 （以下など）さくらVPS（<a href="https://vps.sakura.ad.jp/">https://vps.sakura.ad.jp/</a>）</li>

<h1>以下の手順でWordpressをインストールする。</h1>
<ul>
<li>ターミナルを起動し、SSH（以下のコマンド）でサーバーにアクセスする。</li>
</ul>
<pre><code>ssh root@[IP]
</code></pre>
<p>※上記の「[IP]」には自身のサーバーのIPを代入すること（以下のようになる）</p>
<pre><code>ssh root@111.222.33.44
</code></pre>
<ul>
<li>mariadb（MySQL）をインストール</li>
</ul>
<pre><code>yum install mariadb mariadb-server
</code></pre>
<ul>
<li>DBの自動起動設定</li>
</ul>
<pre><code>systemctl enable mariadb.service
</code></pre>
<ul>
<li>DB起動</li>
</ul>
<pre><code>systemctl start mariadb.service
</code></pre>
<ul>
<li>MySQLにログイン</li>
</ul>
<pre><code class="hljs language-sql">mysql <span class="hljs-operator">-</span>u root
</code></pre>
<ul>
<li>DBを作成</li>
</ul>
<pre><code class="hljs language-sql"><span class="hljs-keyword">create</span> database wordpress;
</code></pre>
<ul>
<li>rootのパスワードを設定</li>
</ul>
<pre><code class="hljs language-sql"><span class="hljs-keyword">update</span> mysql.user <span class="hljs-keyword">set</span> password<span class="hljs-operator">=</span>password(<span class="hljs-string">'password'</span>) <span class="hljs-keyword">where</span> <span class="hljs-keyword">user</span> <span class="hljs-operator">=</span> <span class="hljs-string">'root'</span>;
</code></pre>
<ul>
<li>設定を反映</li>
</ul>
<pre><code class="hljs language-sql">flush privileges;
</code></pre>
<ul>
<li>MySQLログアウト</li>
</ul>
<pre><code class="hljs language-sql">exit;
</code></pre>
<ul>
<li>PHPをインストール（LAMPでインストールされているが、足りないモジュールがあるため）</li>
</ul>
<pre><code>yum -y install php
</code></pre>
<ul>
<li>ファイアーウォールを起動（CentOS7起動時には停止されている）</li>
</ul>
<pre><code>systemctl start firewalld
</code></pre>
<ul>
<li>ポート８０を開放</li>
</ul>
<pre><code>firewall-cmd --add-port=80/tcp --zone=public --permanent
</code></pre>
<ul>
<li>ファイアーウォールの再起動</li>
</ul>
<pre><code>firewall-cmd --reload
</code></pre>
<ul>
<li>Apacheの起動</li>
</ul>
<pre><code>systemctl start httpd
</code></pre>
<ul>
<li>Apacheのデーモン化（サーバー起動時に、自動起動するように設定）</li>
</ul>
<pre><code>systemctl enable httpd
</code></pre>
<ul>
<li>Apacheのルートに移動</li>
</ul>
<pre><code>cd /var/www/html/
</code></pre>
<ul>
<li>Wordpressをインストール（Zipをダウンロード）</li>
</ul>
<pre><code>wget https://ja.wordpress.org/wordpress-4.4.2-ja.zip
</code></pre>
<ul>
<li>Wordpressを解凍</li>
</ul>
<pre><code>unzip wordpress-4.4.2-ja.zip
</code></pre>
<ul>
<li>権限をApacheで設定（「wordpress」ディレクトリにApacheでアクセスできるようにする）</li>
</ul>
<pre><code>chown -R apache. wordpress
</code></pre>
<ul>
<li>Apacheの再起動</li>
</ul>
<pre><code>systemctl restart httpd
</code></pre>

<li>以下のURLにアクセスして、Wordpressの手順に沿ってインストールする。http://[IP]/wordpress/</li>
