13:T3771,<h2>■はじめに</h2>
<p>本記事では、「UIPageControl」「UIScrollView」を使用して、横スクロールのよくあるチュートリアル画面を作る方法をまとめています。
使用している画像はサンプルの画像なので、チュートリアルの画像に差し替えて使用してください。</p>
<p><img src="/images/2020-05-03-000000-1/20220707140432.png" alt=""></p>
<h2>■手順</h2>
<p>ソースコードは、<a href="https://github.com/nakkann-1013/PageControlSample_ios">こちら</a>にアップしていますので、とりあえず動かしてみたい方はクローンして確認してください。</p>
<p>本記事の方法だと、スクロールした時に、以下のようにUIPageControlが切り替わるようになります。</p>
<p><img src="/images/2020-05-03-000000-1/20220707140423.png" alt=""></p>
<p><img src="/images/2020-05-03-000000-1/20220707140426.png" alt=""></p>
<p>フィールドに、今回のチュートリアルで使用する「UIPageControl」「UIScrollView」の定義と、使用する画像名を保持しているリストを宣言します。</p>
<pre><code class="hljs language-swift"><span class="hljs-keyword">var</span> pageControl: <span class="hljs-type">UIPageControl</span>!
<span class="hljs-keyword">var</span> scrollView: <span class="hljs-type">UIScrollView</span>!

<span class="hljs-comment">// 表示する画像の名前のリスト</span>
<span class="hljs-keyword">let</span> imageArray <span class="hljs-operator">=</span> [<span class="hljs-string">"memoruntyo"</span>, <span class="hljs-string">"dc_dentaku"</span>, <span class="hljs-string">"fx_sp"</span>, <span class="hljs-string">"check_imikotoba"</span>, <span class="hljs-string">"patata_talk"</span>, <span class="hljs-string">"patata_wiq"</span>, <span class="hljs-string">"shiftter"</span>]
</code></pre>
<p>「viewDidLoad」にて、画面のサイズを取得して定数として定義した後に、スクロールビューの定義を行います。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// 画面の横のサイズを取得する</span>
<span class="hljs-keyword">let</span> scWidth <span class="hljs-operator">=</span> <span class="hljs-keyword">self</span>.view.frame.width
<span class="hljs-comment">// 画面の縦のサイズを取得する</span>
<span class="hljs-keyword">let</span> scHeight <span class="hljs-operator">=</span> <span class="hljs-keyword">self</span>.view.frame.height

<span class="hljs-comment">// ScrollViewを取得する</span>
scrollView <span class="hljs-operator">=</span> <span class="hljs-type">UIScrollView</span>()
scrollView.frame <span class="hljs-operator">=</span> <span class="hljs-type">CGRect</span>(x: <span class="hljs-number">0</span>, y: <span class="hljs-number">0</span>, width: scWidth, height: scHeight)
<span class="hljs-comment">// 横方向のスクロールバーを非表示にする</span>
scrollView.showsHorizontalScrollIndicator <span class="hljs-operator">=</span> <span class="hljs-literal">false</span>;
<span class="hljs-comment">// 縦方向のスクロールバーを非表示にする</span>
scrollView.showsVerticalScrollIndicator <span class="hljs-operator">=</span> <span class="hljs-literal">false</span>
<span class="hljs-comment">// ページングを許可する（中途半端な位置でスクロールが止まらないように設定）</span>
scrollView.isPagingEnabled <span class="hljs-operator">=</span> <span class="hljs-literal">true</span>
<span class="hljs-comment">// ScrollViewのデリゲートを設定する</span>
scrollView.delegate <span class="hljs-operator">=</span> <span class="hljs-keyword">self</span>
<span class="hljs-comment">// スクロールの画面サイズを指定する</span>
scrollView.contentSize <span class="hljs-operator">=</span> <span class="hljs-type">CGSize</span>(width: <span class="hljs-type">CGFloat</span>(imageArray.count) <span class="hljs-operator">*</span> scWidth, height: <span class="hljs-number">0</span>)
<span class="hljs-comment">// ScrollViewをViewに追加する</span>
<span class="hljs-keyword">self</span>.view.addSubview(scrollView)
</code></pre>
<p>「viewDidLoad」にて、上記で定義したスクロールビューにチュートリアルの画像を設定します。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// 画像をページ数分設定する</span>
<span class="hljs-keyword">for</span> i <span class="hljs-keyword">in</span> <span class="hljs-number">0</span> <span class="hljs-operator">..&#x3C;</span> imageArray.count {

    imgView.frame <span class="hljs-operator">=</span> <span class="hljs-type">CGRect</span>(x: <span class="hljs-type">CGFloat</span>(i) <span class="hljs-operator">*</span> scWidth, y: <span class="hljs-number">0</span>, width: scWidth, height: scHeight)
    imgView.image <span class="hljs-operator">=</span> <span class="hljs-type">UIImage</span>(named: imageArray[i])
    scrollView.addSubview(imgView)
}
</code></pre>
<p>「viewDidLoad」にて、ページコントロールの定義を行います。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">// PageControlを作成する</span>
pageControl <span class="hljs-operator">=</span> <span class="hljs-type">UIPageControl</span>(frame: <span class="hljs-type">CGRect</span>(x: <span class="hljs-number">0</span>, y: scHeight <span class="hljs-operator">-</span> <span class="hljs-number">50</span>, width: scWidth, height: <span class="hljs-number">50</span>))
<span class="hljs-comment">// PageControlするページ数を設定する</span>

<span class="hljs-comment">// 現在ページを設定する</span>
pageControl.currentPage <span class="hljs-operator">=</span> <span class="hljs-number">0</span>
<span class="hljs-comment">// 「pageControl」のタップイベントを止める</span>
pageControl.isUserInteractionEnabled <span class="hljs-operator">=</span> <span class="hljs-literal">false</span>
<span class="hljs-comment">// pageControlをViewに追加する</span>
<span class="hljs-keyword">self</span>.view.addSubview(pageControl)
</code></pre>
<p>「scrollViewDidEndDecelerating」の関数を定義し、その内部にて、ページが切り替わった際には、ページコントロールも切り替えるように処理を追加します。</p>
<pre><code class="hljs language-swift"><span class="hljs-comment">/// スクロール終了後の処理</span>
<span class="hljs-comment">/// - Parameter scrollView: scrollView description</span>
<span class="hljs-keyword">func</span> <span class="hljs-title function_">scrollViewDidEndDecelerating</span>(<span class="hljs-keyword">_</span> <span class="hljs-params">scrollView</span>: <span class="hljs-type">UIScrollView</span>) {
    <span class="hljs-comment">// スクロール数が1ページ分になったら時</span>
    <span class="hljs-keyword">if</span> fmod(scrollView.contentOffset.x, scrollView.frame.maxX) <span class="hljs-operator">==</span> <span class="hljs-number">0</span> {
        <span class="hljs-comment">// ページの場所を切り替える</span>
        pageControl.currentPage <span class="hljs-operator">=</span> <span class="hljs-type">Int</span>(scrollView.contentOffset.x <span class="hljs-operator">/</span> scrollView.frame.maxX)
    }
}
</code></pre>
<p>これで、よく見る横スクロールのチュートリアルの完成です。</p>
