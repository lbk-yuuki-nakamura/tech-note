13:Tced,<h2>■はじめに</h2>
<p>Firebase Cloud Messaging（以降、FCM）でPush通知を送信するため、「Server Key」と、送信先の「Device Token」が取得できている前提として本手順を記載します。</p>
<h2>■手順</h2>
<p>Node.jsからFCMに対して、リクエストを送るために、以下のコマンドで、「request」のnpmモジュールをインストールする。</p>
<pre><code>npm install request --save
</code></pre>
<p>FCMを送るために、「 <a href="https://fcm.googleapis.com/fcm/send">https://fcm.googleapis.com/fcm/send</a> 」に対してPOSTリクエストを行い、通知を送ります。</p>
<p>Bodyに通知の情報を設定する必要があります。</p>
<p>以下に、FCMの通知を送信する関数を記載します。</p>
<pre><code class="hljs language-js"><span class="hljs-comment">/**
 * プッシュ通知送信処理
 * <span class="hljs-doctag">@param</span> {<span class="hljs-type">*</span>} serverKey　サーバーキー
 * <span class="hljs-doctag">@param</span> {<span class="hljs-type">*</span>} deviceToken デバイストークン
 * <span class="hljs-doctag">@param</span> {<span class="hljs-type">*</span>} title タイトル
 * <span class="hljs-doctag">@param</span> {<span class="hljs-type">*</span>} message メッセージ
 */</span>
<span class="hljs-keyword">function</span> <span class="hljs-title function_">pushMessage</span>(<span class="hljs-params">serverKey, deviceToken, title, message</span>) {
    <span class="hljs-keyword">var</span> headers = {
        <span class="hljs-string">'Content-Type'</span>: <span class="hljs-string">'application/json'</span>,
        <span class="hljs-string">'Authorization'</span>: <span class="hljs-string">'key='</span> + serverKey
    };

    <span class="hljs-keyword">var</span> dataString = <span class="hljs-string">'{"to": "'</span> + deviceToken + <span class="hljs-string">'", "notification": {"title": "'</span> + title + <span class="hljs-string">'", "body": "'</span> + message + <span class="hljs-string">'", "sound": "default"}, "priority":"high"}'</span>;

    <span class="hljs-keyword">var</span> options = {
        <span class="hljs-attr">url</span>: <span class="hljs-string">'https://fcm.googleapis.com/fcm/send'</span>,
        <span class="hljs-attr">method</span>: <span class="hljs-string">'POST'</span>,
        <span class="hljs-attr">headers</span>: headers,
        <span class="hljs-attr">body</span>: dataString
    };

    <span class="hljs-title function_">request</span>(options, callback);
}
