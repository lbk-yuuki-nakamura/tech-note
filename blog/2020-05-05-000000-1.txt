13:T125a,<h2>■はじめに</h2>
<p>サードパーティ製のライブラリを使用する際に、MITライセンスや、Apatchライセンスなどのライセンスのルールで、ライセンスの内容を表示することが必要になります。</p>
<p>アプリ内にライセンス表示画面を出すことでも対応できますが、それだと保守が面倒だし、抜けが出る可能性があります。</p>
<p>そこで、「LicensePlist」という素晴らしいライブラリを見つけましたので、ここではこのライブラリを使用してライセンス表示を行います。</p>
<p>※このライブラリでは、iPhoneの「設定」アプリ内の下の方に自分のアプリが表示されるので、その中に「License」が選択できるようになります。</p>
<h2>■手順</h2>
<p>プロジェクトのPodfileに以下を記載する。</p>
<pre><code>pod 'LicensePlist'
</code></pre>
<p>その後、以下のコマンドをターミナルで実行し、ライブラリをインストールする。</p>
<pre><code>pod install
</code></pre>
<p>Xcodeでプロジェクトを開き、「Build Phases」の「＋」から「New Run Script Phase」を選択し、以下のShellを記載する。</p>
<p><img src="https://developer-kuro.com/develop/wp-content/uploads/2019/12/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88-2019-12-24-12.09.43-300x56.png" alt=""></p>
<pre><code>if [ $CONFIGURATION = "Debug" ]; then
    ${PODS_ROOT}/LicensePlist/license-plist --output-path $PROJECT_NAME/Settings.bundle
fi
</code></pre>
<p><img src="https://developer-kuro.com/develop/wp-content/uploads/2019/12/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88-2019-12-24-12.09.50-300x51.png" alt=""></p>
<p>プロジェクトディレクトリを右クリックし、「New File...」を選択する。</p>
<p><img src="https://developer-kuro.com/develop/wp-content/uploads/2019/12/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88-2019-12-24-12.13.22-300x155.png" alt=""></p>
<p>「Settings Bundle」を選択し、作成する。</p>
<p>※ファイル名は「Settings」のままにしておくこと。</p>
<p><img src="https://developer-kuro.com/develop/wp-content/uploads/2019/12/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88-2019-12-24-12.13.36-300x216.png" alt=""></p>
<p>生成された「Settings.bundle」内の「en.lproj」ディレクトリを削除する。</p>
<p><img src="https://developer-kuro.com/develop/wp-content/uploads/2019/12/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88-2019-12-24-12.13.56.png" alt=""></p>
<p>「Settings.bundle」内の「Root.plist」をSource Codeで開き、以下に書き換える。（元々の記述は全て削除する。）</p>
<p><img src="https://developer-kuro.com/develop/wp-content/uploads/2019/12/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88-2019-12-24-12.14.18-300x124.png" alt=""></p>
<pre><code>&#x3C;?xml version="1.0" encoding="UTF-8"?>
&#x3C;!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">

PreferenceSpecifiers

                Title
                Licenses
                Type
                PSChildPaneSpecifier
                File
                com.mono0926.LicensePlist

        StringsTable
        Root

</code></pre>
<p>書き換えて、ビルドを行うと、「Settings.bundle」配下に以下が追加される。</p>
<p><img src="https://developer-kuro.com/develop/wp-content/uploads/2019/12/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88-2019-12-24-12.16.06-300x89.png" alt=""></p>
<p>ここまで、できたら実機ビルドを行い、アプリが起動した後に「設定」アプリの下部にある自分のアプリを開くと「Licenses」の項目が追加されている。</p>
<p><img src="/images/2020-05-05-000000-1/20220707140511.png" alt=""></p>
<p>この「Licenses」を選択すると、利用しているライブラリの一覧が表示される。</p>
<p>※以下は、ライブラリはLicensePlistしか使用していない場合です。</p>
<p>※他のライブラリを使用した場合も自動で設定してくれるようです。</p>
<p><img src="/images/2020-05-05-000000-1/20220707140515.png" alt=""></p>
