<p>プロジェクトの構成は以下です。</p>
<ul>
<li>Project　# プロジェクトの一番親のディレクトリDog　# 犬の画像を格納するディレクトリ</li>
<li>Cat　# 猫の画像を格納するディレクトリ</li>
<li>Check　# 分類したい画像を格納するディレクトリ</li>
<li>learning.py　# データセットを生成するPythonファイル</li>
<li>match.py　# 画像分類を行うPythonファイル</li>
</ul>
<p>ソースコードの全量は以下です。（「TARGET_FILE」の画像名は、チェックしたい画像名に変更してください。）</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> cv2
<span class="hljs-keyword">import</span> numpy

sam = numpy.load(<span class="hljs-string">'./filename.npz'</span>)

TARGET_FILE = <span class="hljs-string">'./Check/check.png'</span>
IMG_SIZE = (<span class="hljs-number">50</span>, <span class="hljs-number">50</span>)

target_img = cv2.imread(TARGET_FILE)
target_img = cv2.resize(target_img, IMG_SIZE)
target_hist = cv2.calcHist([target_img], [<span class="hljs-number">0</span>], <span class="hljs-literal">None</span>, [<span class="hljs-number">256</span>], [<span class="hljs-number">0</span>, <span class="hljs-number">256</span>])

<span class="hljs-keyword">for</span> i <span class="hljs-keyword">in</span> <span class="hljs-built_in">range</span>(<span class="hljs-number">0</span>, <span class="hljs-built_in">len</span>(labelList)):
    comparing_img = sam[<span class="hljs-string">'trainimg'</span>][i]
    comparing_img = cv2.resize(comparing_img, IMG_SIZE)
    comparing_hist = cv2.calcHist([comparing_img], [<span class="hljs-number">0</span>], <span class="hljs-literal">None</span>, [<span class="hljs-number">256</span>], [<span class="hljs-number">0</span>, <span class="hljs-number">256</span>])

    ret = cv2.compareHist(target_hist, comparing_hist, <span class="hljs-number">0</span>)
    <span class="hljs-built_in">print</span>(sam[<span class="hljs-string">'type'</span>][i], sam[<span class="hljs-string">'trainlabel'</span>][i], ret)
