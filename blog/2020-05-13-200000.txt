13:T1082,<h1>もくじ</h1>
<h1>■はじめに</h1>
<p>fastlaneの環境構築はできている前提で記載しています。</p>
<p>AppStoreへのリリースビルドのlaneの解説です。</p>
<h1>■手順</h1>
<h2>fastlaneの生成</h2>
<p>cdコマンドでプロジェクトのディレクトリをカレントディレクトリにする。</p>
<p>以下のコマンドで、fastlaneの初期化をする。</p>
<pre><code>fastlane init
</code></pre>
<p>質問は割愛しますが、最初の質問？のテンプレートを使うかどうか？は使用しないようにしてください。</p>
<h2>AppStoreへのリリースビルドのlaneを作成</h2>
<p>以下のファイルをテキストエディタなどで開く</p>
<pre><code>/プロジェクト/fastlane/Fastfile
</code></pre>
<p>以下の記載を行う。</p>
<pre><code>default_platform(:ios)

platform :ios do

  lane :release_app do
    build_app(scheme: "[アプリ名]",
            workspace: "[アプリ名].xcworkspace",
            include_bitcode: true)
    upload_to_app_store(
      username: "[Apple ID]",
      force: true,
      skip_screenshots: true,
      skip_metadata: true
    )
  end
end
</code></pre>
<p>以下に関しては、それぞれの環境で書き換えてください。</p>
<pre><code>[アプリ名]
</code></pre>
<pre><code>[Apple ID]
</code></pre>
<h2>AppStoreへのリリースビルドのlaneの解説</h2>
<p>以下は、アプリをビルドするフローです。</p>
<pre><code>build_app(scheme: "[アプリ名]",
            workspace: "[アプリ名].xcworkspace",
            include_bitcode: true)
</code></pre>
<p>以下はAppStoreへIPAをアップロードするフローです。</p>
<pre><code>upload_to_app_store(
      username: "[Apple ID]",
      force: true,
      skip_screenshots: true,
      skip_metadata: true
    )
</code></pre>
<h2>upload_to_app_storeのオプション</h2>
<p>以下のオプションは、HTMLのプレビューをスキップするオプションです。</p>
<p>trueとすることで、HTMLプレビューをスキップできます。</p>
<pre><code>force
</code></pre>
<p>以下のオプションは、スクリーンショットのアップロードスキップするオプションです。</p>
<p>trueとすることで、スクリーンショットのアップロードスキップできます。</p>
<pre><code>skip_screenshots
</code></pre>
<p>以下のオプションは、メタデータ（アプリの説明など）のアップロードスキップするオプションです。</p>
<p>trueとすることで、メタデータ（アプリの説明など）のアップロードスキップできます。</p>
<pre><code>skip_metadata
</code></pre>
<h2>ビルド番号の自動インクリメント</h2>
<p>アプリバージョンならまだしも、ビルドバージョンをいちいち書き換えるのは面倒ですよね？</p>
<p>以下の記載をlaneに追加することで、ビルドバージョンを自動で追加することができます。</p>
<p>注意点として、ビルド番号は以下の形式にする必要があります。</p>
<p>※純粋な数字にしてください。</p>
<pre><code>【OK】
1
【NG】
1.0
</code></pre>
<p>【ビルド番号のインクリメント　lane】</p>
<pre><code>increment_build_number
</code></pre>
<p>ちなみに、以下でGitにPushできます。</p>
<pre><code>commit_version_bump(
      force: true
    )

    push_to_git_remote(
      force: true
    )
</code></pre>
<h2>全て合わせたlane</h2>
<p>上記の内容を全て合わせたlaneは以下です。</p>
<pre><code>default_platform(:ios)

platform :ios do

  lane :release_app do

    increment_build_number
    commit_version_bump(
      force: true
    )
    push_to_git_remote(
      force: true
    )
    build_app(scheme: "[アプリ名]",
            workspace: "[アプリ名].xcworkspace",
            include_bitcode: true)
    upload_to_app_store(
      username: "[Apple ID]",
      force: true,
      skip_screenshots: true,
      skip_metadata: true
    )

  end
end
</code></pre>
<p>以下のコマンドでlaneを実行することができます。</p>
<pre><code>fastlane release_app
