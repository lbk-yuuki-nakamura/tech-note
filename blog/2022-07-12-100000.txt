<h1>前提</h1>
<p>Node.jsの環境が用意されていること。</p>
<p>まだの人は以下からNode.jsをインストールしておいてください。</p>
<p><a href="https://reigle.info/entry/2020/04/29/000000_2">https://reigle.info/entry/2020/04/29/000000_2</a></p>
<h1>Reactのプロジェクト作成環境の用意</h1>
<p>以下のコマンドを実行し、<code>yarn</code>をインストールする</p>
<pre><code>npm install --global yarn
</code></pre>
<p>以下のコマンドを実行し、<code>create-react-app</code>をインストールする</p>
<pre><code>yarn global add create-react-app
</code></pre>
<h1>Reactプロジェクトに「TypeScript」の設定をしてプロジェクト作成</h1>
<p>以下のコマンドを実行し、プロジェクトを作成する</p>
<p>「<code>[プロジェクト名]</code>」は各自で設定すること</p>
<pre><code>npx create-react-app [プロジェクト名] --template typescript
</code></pre>
<p>上記のように「<code>template</code>」オプションで「<code>typescript</code>」を指定するだけで、TypeScriptが設定されたReactプロジェクトが作成できる</p>
<h1>Dockerの組み込み</h1>
<p>以下のDockerの公式サイトから、<code>Docker Desktop</code>アプリをインストールする。</p>
<p>インストール後は手順に沿って、<code>Docker Desktop</code>を起動して確認してください。</p>
<p><a href="https://docs.docker.com/desktop/mac/install/">https://docs.docker.com/desktop/mac/install/</a></p>
<p>以下のコマンドを実行して、Dockerのバージョンが表示されればDockerの準備は完了です。</p>
<pre><code>docker -v
</code></pre>
<p>プロジェクトのルート（「<code>package.json</code>」などがある場所）に「<code>Dockerfile</code>」を作成する</p>
<p><code>Dockerfile</code>には以下の内容を記述する（nodeのバージョンは任意で変更してください）</p>
<pre><code>FROM node:16.14.2
WORKDIR /src
</code></pre>
<p>プロジェクトのルート（「<code>package.json</code>」などがある場所）に「<code>docker-compose.yml</code>」を作成する</p>
<p><code>docker-compose.yml</code>には以下の内容を記述する</p>
<pre><code># docker-composeのバージョン
# [https://docs.docker.jp/compose/compose-file/compose-file-v3.html](https://docs.docker.jp/compose/compose-file/compose-file-v3.html)
version: '3.8'

services:
  react-app:
    # 環境構築
    # dockerfileを指定して「Dockerfile」にて環境構築を実施
    build:
      context: .
      dockerfile: Dockerfile
    # バインドマウント、ホスト側のファイルやディレクトリをコンテナ側にマウント
    volumes:
      - ./:/src
    # 起動時コマンド
    command: sh -c "npm install &#x26;&#x26; npm run start"
    # ホスト側とコンテナ側の両方のポートを指定(ホスト側 : コンテナ側)
    # ポートを1つのみ指定した場合は、ホスト側にランダムなポート番号が割り当てられる
    ports:
      - "3000:3000"
    # 標準入出力とエラー出力をコンテナに結びつける
    stdin_open: true
</code></pre>
<p>ここまで準備ができたら、Dockerを起動してみます。
以下のコマンドを実行してください。</p>
<pre><code>docker-compose up
</code></pre>
<p>ログで以下が表示されたら、起動は完了です。</p>
<pre><code>webpack compiled successfully
</code></pre>
<p>以下のURLにアクセスして起動されていることを確認してください。</p>
<p><a href="http://localhost:3000/">http://localhost:3000/</a></p>
<p>ここまでのソースコードは以下のGitHubにアップしています。</p>
<p><a href="https://github.com/Reigle/react-typescript-template/tree/template_1">https://github.com/Reigle/react-typescript-template/tree/template_1</a></p>
