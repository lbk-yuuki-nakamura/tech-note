13:Te8d,<h1>async（非同期処理）</h1>
<p>関数の前に「<code>async</code>」を付ける事で、非同期の関数になります。</p>
<p>そもそも、非同期とは順番を待たずに後ろで処理をしておくという状態です。</p>
<p>非同期にする事で、APIなど裏で実施したい内容を実行する事ができます。</p>
<p>以下、非同期のサンプルコードです。</p>
<p>※無名関数を使用して、シンプルに記載しています。</p>
<pre><code class="hljs language-javascript">&#x3C;script>
    (<span class="hljs-title function_">async</span> () => {
        <span class="hljs-comment">// ここが非同期処理です。</span>
        <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(<span class="hljs-string">'非同期処理'</span>);
    })()
&#x3C;/script>
</code></pre>
<h1>await（同期処理）</h1>
<p>非同期処理の中で、画面の表示を変えたいなど同期的に処理を行いたい場合があります。
その際には、明示的に同期処理を実行することが出来ます。
処理の左に「<code>await</code>」を付ける事で、同期処理になります。</p>
<p>以下、同期処理のサンプルコードです。</p>
<p>※無名関数を使用して、シンプルに記載しています。</p>
<pre><code class="hljs language-javascript">&#x3C;script>
    (<span class="hljs-title function_">async</span> () => {
        <span class="hljs-comment">// 以下が同期処理です。</span>
        <span class="hljs-keyword">await</span> <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(<span class="hljs-string">'同期処理'</span>);
    })()
&#x3C;/script>
</code></pre>
<h1>非同期処理と同期処理まとめ</h1>
<p>まずはソースコードの全量</p>
<p>「<code>await</code>」の右の処理は、１秒止める処理だと思ってください。</p>
<pre><code class="hljs language-javascript">&#x3C;script>
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(<span class="hljs-string">'ログ1'</span>);
    (<span class="hljs-title function_">async</span> () => {
        <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(<span class="hljs-string">'ログ2'</span>);
        <span class="hljs-keyword">await</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">Promise</span>(<span class="hljs-function"><span class="hljs-params">resolve</span> =></span> <span class="hljs-built_in">setTimeout</span>(resolve, <span class="hljs-number">1000</span>))
        <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(<span class="hljs-string">'ログ3'</span>);
    })()
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(<span class="hljs-string">'ログ4'</span>);
&#x3C;/script>
</code></pre>
