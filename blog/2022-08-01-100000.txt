13:T10a1,<h1>環境</h1>
<p>VPS環境を想定して記載する。</p>
<p>各種環境は以下とするので、読み替えて下さい。</p>
<p>IP：999.99.99.999</p>
<p>ドメイン：example.com</p>
<h1>サーバー環境準備</h1>
<p>サーバーにSSH接続</p>
<pre><code class="hljs language-sh">ssh root@999.99.99.999
</code></pre>
<p>必要なパッケージのインストール</p>
<pre><code class="hljs language-sh">yum install yum-utils
yum install https://dl.fedoraproject.org/pub/epel/epel-release-latest-7.noarch.rpm
yum install http://rpms.remirepo.net/enterprise/remi-release-7.rpm
</code></pre>
<h1>nginxの環境構築</h1>
<h2>nginxのインストール</h2>
<p>nginxのインストール用の定義を記載するために、以下のコマンドを実行する。</p>
<pre><code class="hljs language-sh">vi /etc/yum.repos.d/nginx.repo
</code></pre>
<p>「<code>/etc/yum.repos.d/nginx.repo</code>」の内容は以下を記載する。</p>
<pre><code class="hljs language-sh">[nginx]
name=nginx stable repo
baseurl=http://nginx.org/packages/centos/<span class="hljs-variable">$releasever</span>/<span class="hljs-variable">$basearch</span>/
gpgcheck=1
enabled=0
gpgkey=https://nginx.org/keys/nginx_signing.key
</code></pre>
<p>以下のコマンドでnginxのインストールを実行する。</p>
<pre><code class="hljs language-sh">yum-config-manager --<span class="hljs-built_in">enable</span> nginx
yum install nginx
</code></pre>
<h2>nginxの起動、自動起動設定</h2>
<p>以下のコマンドでnginxの起動と、サーバー再起動後の自動起動の設定を行う。</p>
<pre><code class="hljs language-sh">systemctl start nginx
systemctl <span class="hljs-built_in">enable</span> nginx
</code></pre>
<h2>nginxのバージョン非表示</h2>
<p>nginx のバージョンを表示にするための設定を行うために以下のコマンドを実行します。</p>
<pre><code class="hljs language-sh">vi /etc/nginx/nginx.conf
</code></pre>
<p>ファイル内に、以下の記述を追加します。
（用意されている「<code>http</code>」の中括弧の中に「<code>server_tokens off;</code>」を追加します。）</p>
<pre><code class="hljs language-sh">http {
  ~~~~~省略~~~~~
  server_tokens off;
  ~~~~~省略~~~~~
}
</code></pre>
<p>nginxを再起動して上記の設定を反映させます。</p>
<pre><code class="hljs language-sh">systemctl restart nginx
</code></pre>
<h1>ファイアーウォールの設定</h1>
<p>以下のコマンドを実行して、「<code>http</code>」「<code>https</code>」のポートを解放します。</p>
<pre><code class="hljs language-sh">firewall-cmd --add-service=http --zone=public --permanent
firewall-cmd --add-service=https --zone=public --permanent
firewall-cmd --reload
</code></pre>
<h1>Let's EncryptのSSL証明書の設定</h1>
<p>必要なパッケージのインストールを行います。</p>
<pre><code class="hljs language-sh">yum install certbot python2-certbot-nginx
</code></pre>
<p>以下で証明書の発行を行います。</p>
<pre><code class="hljs language-sh">certbot --nginx certonly -d example.com
</code></pre>
<h1>nginxのHTTPSリダイレクト設定</h1>
<p>以下のコマンドでドメインの設定ファイルを修正します。</p>
<pre><code class="hljs language-sh">vi /etc/nginx/conf.d/example.com.conf
</code></pre>
<p>以下の内容を記載します。
※Apatchと同じディレクトリ（<code>/var/www/html</code>）をルートにしていますが、各自で任意のディレクトリに変更して下さい。</p>
<pre><code class="hljs language-sh">server {
  listen 443 ssl;
  server_name example.com;
  root /var/www/html;
  index  index.html;

  ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

  ssl_prefer_server_ciphers on;
}

server {
  listen 80;
  server_name example.com;

  <span class="hljs-built_in">return</span> 301 [https://$host<span class="hljs-variable">$request_uri</span>;](https://$host<span class="hljs-variable">$request_uri</span>;)
}
</code></pre>
<p>nginxの再起動を実施します。</p>
<pre><code class="hljs language-sh">systemctl restart nginx
