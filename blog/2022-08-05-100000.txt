13:T1609,<h1>メディアクエリとは</h1>
<p>表示された画面環境に応じて適用するスタイルを切り替える機能。</p>
<p>一つのページで複数の異なる表示環境に対応するレスポンシブWebデザインを実現することができる。</p>
<p>よく使用される例としては、PC版とスマホ版のCSSを分けたい場合などに使用します。</p>
<h1>事前準備</h1>
<p>HTMLのヘッダータグ内に、以下のメタタグを追加します。</p>
<pre><code class="hljs language-javascript">&#x3C;meta name=<span class="hljs-string">"viewport"</span> content=<span class="hljs-string">"width=device-width,initial-scale=1"</span>>
</code></pre>
<h1>スマホにのみCSSを設定する方法</h1>
<p>以下の様に、メディアクエリを設定する事で、スマホにのみ設定できるCSSを記載できます。</p>
<p>一例で「<code>sp_font</code>」のCSSを記載していますが、このクラスが設定されていてもスマホ以外はフォントサイズのCSSが反映されません。</p>
<pre><code class="hljs language-css"><span class="hljs-keyword">@media</span> <span class="hljs-keyword">only</span> screen <span class="hljs-keyword">and</span> (<span class="hljs-attribute">max-width</span>: <span class="hljs-number">479px</span>) {
    <span class="hljs-comment">/* スマートフォン用のCSS */</span>
    <span class="hljs-selector-class">.sp_font</span> {
        <span class="hljs-attribute">font-size</span>: <span class="hljs-number">12px</span>;
    }
}
</code></pre>
<h1>タブレットにのみCSSを設定する方法</h1>
<p>以下の様に、メディアクエリを設定する事で、タブレットにのみ設定できるCSSを記載できます。</p>
<p>一例で「<code>tab_font</code>」のCSSを記載していますが、このクラスが設定されていてもタブレット以外はフォントサイズのCSSが反映されません。</p>
<pre><code class="hljs language-css"><span class="hljs-keyword">@media</span> <span class="hljs-keyword">only</span> screen <span class="hljs-keyword">and</span> (<span class="hljs-attribute">min-width</span>:<span class="hljs-number">479px</span>) <span class="hljs-keyword">and</span> (<span class="hljs-attribute">max-width</span>:<span class="hljs-number">768px</span>) {
    <span class="hljs-comment">/* タブレット用のCSS */</span>
    <span class="hljs-selector-class">.tab_font</span> {
        <span class="hljs-attribute">font-size</span>: <span class="hljs-number">16px</span>;
    }
}
</code></pre>
<h1>PCにのみCSSを設定する方法</h1>
<p>以下の様に、メディアクエリを設定する事で、PCにのみ設定できるCSSを記載できます。</p>
<p>一例で「<code>tab_font</code>」のCSSを記載していますが、このクラスが設定されていてもPC以外はフォントサイズのCSSが反映されません。</p>
<pre><code class="hljs language-css"><span class="hljs-keyword">@media</span> <span class="hljs-keyword">only</span> screen <span class="hljs-keyword">and</span> (<span class="hljs-attribute">min-width</span>: <span class="hljs-number">1200px</span>) {
    <span class="hljs-comment">/* PC用のCSS */</span>
    <span class="hljs-selector-class">.pc_font</span> {
        <span class="hljs-attribute">font-size</span>: <span class="hljs-number">18px</span>;
    }
}
</code></pre>
<h1>問題点</h1>
<p>この記事で記載しているメディアクエリはブラウザの横幅からデバイスを判定しています。</p>
<p>そのため、PCでもウィンドウを小さくすればスマホのCSSが当たります。</p>
<p>また、今後、とてもデカいタブレットが出てきた場合は、そのタブレットにPCのCSSが当たる場合もあります。</p>
