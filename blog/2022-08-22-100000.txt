13:T1012,<h1>インポートのエイリアス化とは</h1>
<p>階層が深くなっていくと、importする際に「<code>../../../../Hoge</code>」のような「<code>../</code>」などの相対パスが複数記載されることがあります。</p>
<p>共通コンポーネントなどは特に複数箇所からの利用が行われるため、上記のようなパスをエイリアスを設定することで、「@Hoge」のようにまとめる事ができます。</p>
<h1>WebPackのエイリアス定義</h1>
<p>以下のようなディレクトリ構造の前提で記載します。</p>
<pre><code class="hljs language-JavaScript">src
  ┣ index.<span class="hljs-property">ts</span>
  ┗components
         ┣ file.<span class="hljs-property">ts</span>
         ┗ dir
            ┗ fileee.<span class="hljs-property">ts</span>
</code></pre>
<p>「<code>webpack.config.js</code>」を以下のようにエイリアスの定義を行います。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-variable language_">module</span>.<span class="hljs-property">exports</span> = <span class="hljs-function">() =></span> {
  <span class="hljs-keyword">return</span> {
    <span class="hljs-attr">resolve</span>: {
      <span class="hljs-attr">alias</span>: {
        <span class="hljs-string">"@dir"</span>: path.<span class="hljs-title function_">join</span>(__dirname, <span class="hljs-string">"src/components/dir/"</span>),
        <span class="hljs-string">"@file"</span>: path.<span class="hljs-title function_">join</span>(__dirname, <span class="hljs-string">"src/components/file.ts"</span>),
      },
      <span class="hljs-attr">extensions</span>: [<span class="hljs-string">".json"</span>, <span class="hljs-string">".js"</span>, <span class="hljs-string">".jsx"</span>, <span class="hljs-string">".ts"</span>, <span class="hljs-string">".tsx"</span>],
    },
    ~~~~~<span class="hljs-title class_">WebPack</span>の定義~~~~~
  };
};
</code></pre>
<h1>TypeScript用のエイリアス定義</h1>
<p>「<code>tsconfig.json</code>」を以下のようにエイリアスの定義を行います。</p>
<pre><code class="hljs language-JavaScript">{
  <span class="hljs-string">"compilerOptions"</span>: {
    ~~~~~tsconfig.<span class="hljs-property">json</span>の他の定義~~~~~
    <span class="hljs-string">"baseUrl"</span>: <span class="hljs-string">"./src"</span>,
    <span class="hljs-string">"paths"</span>: {
      <span class="hljs-string">"@dir/*"</span>: [<span class="hljs-string">"components/dir/*"</span>],
      <span class="hljs-string">"@file"</span>: [<span class="hljs-string">"components/file.ts"</span>]
    }
  },
}
</code></pre>
