GoogleAppScript（GAS）で外部のAPIを実行する方法

2022年8月27日
GoogleAppScript

GASでAPI実行

以下がソースコードの全量です。

※POSTの例です。

「body」にリクエストパラメータを記載してください。

var body = {
  'hoge': 'hogehoge',
};
var options = {
  'method': 'post',
  'contentType': 'application/json',
  'payload': JSON.stringify(body)
};

UrlFetchApp.fetch('https://example.com/hoge', options);

GASでAPI実行箇所をまとめる

以下のようにまとめて記載する事も可能です。

UrlFetchApp.fetch('https://example.com/hoge', {
  'method': 'post',
  'contentType': 'application/json',
  'payload': {
    'hoge': 'hogehoge',
  }
});
