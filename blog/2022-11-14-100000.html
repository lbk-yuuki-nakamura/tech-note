Go言語で変数定義を行う方法

2022年11月14日
Go言語

Go言語の環境構築

以下の記事を参考に、Go言語の環境構築を完了させてください。

https://reigle.info/entry/2022/11/10/100000

初期値なし変数定義

「var 変数名 型」の様な形で変数の定義が可能です。

一例としては、以下です。

var str string

初期値あり変数

「var 変数名 型 = 値」の様な形で変数の定義が可能です。

一例としては、以下です。

var str string = "変数の中身"

「型」に関しては、「値」から推測する事が可能で、「var 変数名 = 値」のように「型」を省略して書くことも可能です。

var str = "変数の中身"

「変数名 := 値」の様に、「var」を省略することも可能です。

str := "変数の中身"
