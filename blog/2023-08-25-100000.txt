13:Td3c,<h1>TypeScriptでのパターンマッチング　ts-patternの使い方</h1>
<p>TypeScriptには標準でパターンマッチングの機能が組み込まれていませんが、<code>ts-pattern</code>というライブラリを使用することで、この機能を取り入れることができます。</p>
<p>今回は、この<code>ts-pattern</code>の基本的な使い方と、複数の条件を組み合わせる方法について解説します。</p>
<h1>ts-patternの導入</h1>
<p>まず、<code>ts-pattern</code>をプロジェクトに導入します。</p>
<pre><code class="hljs language-sh">npm install ts-pattern
</code></pre>
<h1>基本的な使い方</h1>
<p><code>ts-pattern</code>を使うことで、データの形に基づいて処理を分岐させることができます。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">import</span> { match } <span class="hljs-keyword">from</span> <span class="hljs-string">'ts-pattern'</span>;

<span class="hljs-keyword">const</span> result = <span class="hljs-title function_">match</span>(data)
  .<span class="hljs-title function_">with</span>({ <span class="hljs-attr">type</span>: <span class="hljs-string">'dog'</span> }, <span class="hljs-function">() =></span> <span class="hljs-string">"It's a dog!"</span>)
  .<span class="hljs-title function_">otherwise</span>(<span class="hljs-function">() =></span> <span class="hljs-string">"Unknown animal"</span>);
</code></pre>
<p>上記の例では、<code>type</code>プロパティが<code>dog</code>であるかどうかを判定しています。</p>
<h1>複数の条件を組み合わせる</h1>
<p><code>ts-pattern</code>には、複数の条件を組み合わせるための機能が提供されています。</p>
<p><code>P.union</code>を使用することで、2つ以上のパターンを1つに組み合わせることができます。</p>
<p>例として、値がnull、undefined、または空文字列である場合に、特定の処理を行いたいとします。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">import</span> { match, P } <span class="hljs-keyword">from</span> <span class="hljs-string">'ts-pattern'</span>;

<span class="hljs-keyword">const</span> result = <span class="hljs-title function_">match</span>(sample)
  .<span class="hljs-title function_">with</span>(P.<span class="hljs-title function_">union</span>(P.<span class="hljs-property">nullish</span>, <span class="hljs-string">""</span>), <span class="hljs-function">() =></span> <span class="hljs-string">""</span>)
  .<span class="hljs-title function_">otherwise</span>(<span class="hljs-function">(<span class="hljs-params">samp</span>) =></span> samp);
</code></pre>
<p><code>P.union</code>は、与えられた複数のパターンのいずれかにマッチする場合に使用されます。</p>
<h1>まとめ</h1>
<p><code>ts-pattern</code>はTypeScriptでのパターンマッチングを簡単に実現するライブラリです。</p>
<p>特に、複数の条件を組み合わせたい場合には、<code>P.union</code>などの便利な関数が提供されているため、高度なマッチングが可能となります。</p>
