13:Tc32,<h1>JavaScriptのMapオブジェクトをループで処理する方法</h1>
<p>JavaScriptの<code>Map</code>はキーと値のペアを保持するためのコレクションです。</p>
<p>この記事では、<code>Map</code>オブジェクトをループして全件を処理するいくつかの方法を紹介します。</p>
<h1>forEach()を使用する</h1>
<p><code>Map</code>の<code>forEach()</code>メソッドは、Map内の各要素に対して関数を実行します。</p>
<pre><code class="hljs language-JavaScript">map.<span class="hljs-title function_">forEach</span>(<span class="hljs-function">(<span class="hljs-params">value, key</span>) =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(key, value);
});
</code></pre>
<h1>for...ofを使い、entries()を使用する</h1>
<p><code>entries()</code>メソッドは、Map内の各要素のキーと値のペアを返します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">for</span> (<span class="hljs-keyword">let</span> [key, value] <span class="hljs-keyword">of</span> map.<span class="hljs-title function_">entries</span>()) {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(key, value);
}
</code></pre>
<h1>for...ofを使い、keys()を使用する</h1>
<p><code>keys()</code>メソッドは、Map内のすべてのキーを返します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">for</span> (<span class="hljs-keyword">let</span> key <span class="hljs-keyword">of</span> map.<span class="hljs-title function_">keys</span>()) {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(key, map.<span class="hljs-title function_">get</span>(key));
}
</code></pre>
<h1>for...ofを使い、values()を使用する</h1>
<p><code>values()</code>メソッドは、Map内のすべての値を返します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">for</span> (<span class="hljs-keyword">let</span> value <span class="hljs-keyword">of</span> map.<span class="hljs-title function_">values</span>()) {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(value);
}
</code></pre>
<h1>Object Destructuringを使用する</h1>
<p><code>for...of</code>ループは、デフォルトでMapの<code>entries()</code>メソッドの出力を返します。</p>
<p>そのため、オブジェクトの分割代入を使用してキーと値を取得することができます。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">for</span> (<span class="hljs-keyword">let</span> [key, value] <span class="hljs-keyword">of</span> map) {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(key, value);
}
</code></pre>
