13:Taca,<h1>JavaScriptで現在のURLを取得する方法</h1>
<p>Webページ上で現在のURLを取得する必要があるとき、JavaScriptはこのタスクを簡単にこなすことができます。</p>
<p>以下は、どのようにしてそれを達成できるかについてのガイドです。</p>
<h1><code>window.location</code>オブジェクトとは</h1>
<p><code>window.location</code>は、ブラウザのウィンドウやタブで表示されている現在のURLに関する詳細情報を提供するオブジェクトです。</p>
<h1>完全なURLの取得</h1>
<p>以下の方法で現在のページの完全なURLを取得できます。</p>
<pre><code>var currentURL = window.location.href;
console.log(currentURL);
</code></pre>
<p>たとえば、ページのURLが<code>https://example.com:8080/path/to/page?query=value#section</code>の場合、上記のコードはこの完全なURLをコンソールに出力します。</p>
<h1>URLの各部分へのアクセス</h1>
<p><code>window.location</code>にはURLの各部分に直接アクセスするためのプロパティがたくさんあります。
以下はその一部です。</p>
<ul>
<li><strong>Protocol</strong>: <code>window.location.protocol</code>を使用してURLのプロトコルを取得します。
<ul>
<li>例: <code>https:</code></li>
</ul>
</li>
<li><strong>Host</strong>: <code>window.location.host</code>はホスト名とポート番号を含みます。
<ul>
<li>例: <code>example.com:8080</code></li>
</ul>
</li>
<li><strong>Hostname</strong>: <code>window.location.hostname</code>でホスト名のみを取得します。
<ul>
<li>例: <code>example.com</code></li>
</ul>
</li>
<li><strong>Port</strong>: <code>window.location.port</code>を使用してポート番号を取得します。
<ul>
<li>例: <code>8080</code></li>
</ul>
</li>
<li><strong>Path</strong>: <code>window.location.pathname</code>でURLのパス部分を取得します。
<ul>
<li>例: <code>/path/to/page</code></li>
</ul>
</li>
<li><strong>Query String</strong>: <code>window.location.search</code>を使用してクエリ文字列を取得します。
<ul>
<li>例: <code>?query=value</code></li>
</ul>
</li>
<li><strong>Hash Fragment</strong>: <code>window.location.hash</code>を使用してハッシュフラグメントを取得します。
<ul>
<li>例: <code>#section</code></li>
</ul>
</li>
</ul>
<h1>まとめ</h1>
<p><code>window.location</code>オブジェクトを使用することで、JavaScriptを使用してWebページのURLの各部分に簡単にアクセスすることができます。</p>
