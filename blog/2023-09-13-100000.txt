13:T6bc,<h1><code>useNavigate</code> を使ったURLパラメータに値を設定して React Router での遷移方法</h1>
<p>React Router v6 から、<code>useNavigate</code> という新しいフックが導入されました。</p>
<p>これを使って、プログラム的にルーティングの遷移を行うことができます。</p>
<p>以下は <code>useNavigate</code> を使って、URL パラメータを持つパスに遷移する基本的な方法です。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">import</span> { useNavigate } <span class="hljs-keyword">from</span> <span class="hljs-string">'react-router-dom'</span>;

<span class="hljs-keyword">const</span> <span class="hljs-variable constant_">URL_PATH</span> = <span class="hljs-string">'/path/:id'</span>;
<span class="hljs-keyword">const</span> navigate = <span class="hljs-title function_">useNavigate</span>();

onClick={<span class="hljs-function">() =></span> <span class="hljs-title function_">navigate</span>(<span class="hljs-variable constant_">URL_PATH</span>.<span class="hljs-title function_">replace</span>(<span class="hljs-string">':id'</span>, <span class="hljs-string">'3'</span>))}
</code></pre>
<p>上記のコードは <code>URL_PATH</code> の <code>:id</code> 部分を「3」に置き換え、<code>/path/3</code> というパスへの遷移をトリガーします。</p>
<p><code>replace</code> メソッドを使用することで、<code>URL_PATH</code> の定義を変更せずに動的なパスの生成が可能です。</p>
