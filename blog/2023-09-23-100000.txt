13:Tbb8,<h1>クラス内のGetterについて</h1>
<p>JavaScriptのクラス内において、<code>getter</code>はプロパティ値を取得するためのメソッドです。</p>
<p>これによって、プロパティにアクセスする際に特定のコードを実行することができます。</p>
<h1>ゲッターの定義方法</h1>
<p>ゲッターは <code>get</code> キーワードを使用して定義します。以下に具体的な使用例を示します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">class</span> <span class="hljs-title class_">CustomClass</span> {
  <span class="hljs-title function_">constructor</span>(<span class="hljs-params">message</span>) {
    <span class="hljs-variable language_">this</span>.<span class="hljs-property">str</span> = message || <span class="hljs-string">""</span>;
  }

  <span class="hljs-keyword">get</span> <span class="hljs-title function_">strLength</span>() {
    <span class="hljs-keyword">return</span> <span class="hljs-variable language_">this</span>.<span class="hljs-property">str</span>.<span class="hljs-property">length</span>;
  }
}
</code></pre>
<p>上記の例では、<code>CustomClass</code> クラスに <code>strLength</code> というゲッターを定義しています。</p>
<p>このゲッターは、strの文字数を返します。</p>
<h1>ゲッターの使用方法</h1>
<p>ゲッターは、プロパティと同じようにアクセスできます。</p>
<p>メソッドのように <code>()</code> を付けずにアクセスする点に注意してください。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">const</span> cls = <span class="hljs-keyword">new</span> <span class="hljs-title class_">CustomClass</span>(<span class="hljs-string">"This is an error message."</span>);
<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(cls.<span class="hljs-property">strLength</span>);  <span class="hljs-comment">// 25</span>
</code></pre>
<h1>ゲッターの利点</h1>
<ul>
<li>
<p>ゲッターを使用することで、プロパティの値を取得する際に追加のコードを実行できます。これによって、計算されたプロパティや内部状態の確認が可能となります。</p>
</li>
<li>
<p>ゲッターを利用することで、オブジェクトの内部プロパティへの直接アクセスを避け、カプセル化を向上できます。</p>
</li>
<li>
<p>ゲッターは読み取り専用となりますので、値の変更を防ぐことができます。値の変更が必要な場合は、<code>setter</code>を使用します。</p>
</li>
</ul>
<h1>まとめ</h1>
<p>JavaScriptのクラス内での <code>getter</code> の使用は、プロパティ値の取得やカプセル化、コードの整理に役立ちます。</p>
