13:T133b,<h1>ReactでTailwind CSSをセットアップする</h1>
<p>Tailwind CSSはユーティリティファーストのCSSフレームワークです。</p>
<p>Reactと組み合わせることで、迅速かつ効率的にコンポーネントのスタイリングが可能になります。</p>
<p>本記事では、ReactプロジェクトにTailwind CSSを導入する手順をご紹介します。</p>
<h1>ステップ1: インストール</h1>
<p>まず、新しいReactプロジェクトを作成します。</p>
<pre><code class="hljs language-sh">npx create-react-app my-app
<span class="hljs-built_in">cd</span> my-app
</code></pre>
<p>次に、Tailwind CSSをインストールします。</p>
<pre><code class="hljs language-sh">npm install tailwindcss
</code></pre>
<h1>ステップ2: 設定</h1>
<p>Tailwind CSSの設定ファイルを生成します。</p>
<pre><code class="hljs language-sh">npx tailwindcss init
</code></pre>
<p>これにより、<code>tailwind.config.js</code>ファイルがプロジェクトのルートディレクトリに生成されます。</p>
<p>PostCSSの設定ファイルを作成します。</p>
<pre><code class="hljs language-sh"><span class="hljs-built_in">touch</span> postcss.config.js
</code></pre>
<p>このファイルに以下の内容を追加します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-variable language_">module</span>.<span class="hljs-property">exports</span> = {
  <span class="hljs-attr">plugins</span>: {
    <span class="hljs-attr">tailwindcss</span>: {},
    <span class="hljs-attr">autoprefixer</span>: {},
  },
}
</code></pre>
<p>次に、Tailwind CSSのスタイルシートを作成します。</p>
<pre><code class="hljs language-sh"><span class="hljs-built_in">touch</span> src/tailwind.css
</code></pre>
<p>そして、以下のコードを<code>tailwind.css</code>に追加します。</p>
<pre><code class="hljs language-css"><span class="hljs-keyword">@import</span> <span class="hljs-string">'tailwindcss/base'</span>;
<span class="hljs-keyword">@import</span> <span class="hljs-string">'tailwindcss/components'</span>;
<span class="hljs-keyword">@import</span> <span class="hljs-string">'tailwindcss/utilities'</span>;
</code></pre>
<p><code>src/index.css</code>を以下のように編集して、Tailwind CSSをインポートします。</p>
<pre><code class="hljs language-css"><span class="hljs-keyword">@import</span> <span class="hljs-string">'./tailwind.css'</span>;
</code></pre>
<p>最後に、<code>package.json</code>のscriptsセクションを以下のように編集します。</p>
<pre><code class="hljs language-json"><span class="hljs-attr">"scripts"</span><span class="hljs-punctuation">:</span> <span class="hljs-punctuation">{</span>
  <span class="hljs-attr">"start"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"npm run watch:css &#x26;&#x26; react-scripts start"</span><span class="hljs-punctuation">,</span>
  <span class="hljs-attr">"build"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"npm run build:css &#x26;&#x26; react-scripts build"</span><span class="hljs-punctuation">,</span>
  <span class="hljs-attr">"build:css"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"postcss src/tailwind.css -o src/index.css"</span><span class="hljs-punctuation">,</span>
  <span class="hljs-attr">"watch:css"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"postcss src/tailwind.css -o src/index.css"</span>
<span class="hljs-punctuation">}</span>
</code></pre>
<h1>ステップ3: 使用</h1>
<p>これで、ReactコンポーネントでTailwind CSSのクラスを使用できるようになります。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">function</span> <span class="hljs-title function_">App</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">return</span> (

        <span class="xml"><span class="hljs-tag">&#x3C;<span class="hljs-name">img</span> <span class="hljs-attr">className</span>=<span class="hljs-string">"h-12 w-12"</span> <span class="hljs-attr">src</span>=<span class="hljs-string">"/img/logo.svg"</span> <span class="hljs-attr">alt</span>=<span class="hljs-string">"ChitChat Logo"</span>/></span></span>

        <span class="hljs-title class_">ChitChat</span>

  );
}

<span class="hljs-keyword">export</span> <span class="hljs-keyword">default</span> <span class="hljs-title class_">App</span>;
</code></pre>
