13:T9df,<h1>Dockerを使用してMySQL環境をセットアップする方法</h1>
<p>Dockerを使用すると、数分でMySQLの環境をローカルマシン上でセットアップすることができます。</p>
<p>この記事では、Dockerを利用してMySQL環境を作成する基本的な手順を紹介します。</p>
<h1>1. Docker イメージをPull</h1>
<p>まず、公式のMySQLのDocker イメージをPullします。</p>
<pre><code class="hljs language-sh">docker pull mysql:latest
</code></pre>
<h1>2. Docker コンテナを作成</h1>
<p>Pullしたイメージを元に、Dockerコンテナを起動します。</p>
<p>この時、MySQLのrootユーザのパスワードを設定することができます。</p>
<pre><code class="hljs language-sh">docker run --name mysql-container -e MYSQL_ROOT_PASSWORD=my-secret-pw -d mysql:latest
</code></pre>
<p>上記の<code>mysql-container</code>はコンテナの名前、<code>my-secret-pw</code>はrootユーザのパスワードです。</p>
<p>これらは適宜変更してください。</p>
<h1>3. MySQLに接続</h1>
<p>コンテナを起動した後、以下のコマンドでMySQLサーバに接続できます。</p>
<pre><code class="hljs language-sh">docker <span class="hljs-built_in">exec</span> -it mysql-container mysql -u root -p
</code></pre>
<p>コマンドを実行後、設定したパスワードを入力してください。</p>
<h1>Docker Composeを利用する方法</h1>
<p>もし、より複雑な環境構築が必要な場合や、複数のサービスと連携させる場合には、<code>docker-compose</code>を利用することが推奨されます。</p>
<p>以下は基本的な<code>docker-compose.yml</code>のサンプルです。</p>
<pre><code class="hljs language-sh">version: <span class="hljs-string">'3'</span>

services:
  db:
    image: mysql:latest
    container_name: mysql-container
    environment:
      MYSQL_ROOT_PASSWORD: my-secret-pw
      MYSQL_DATABASE: mydatabase
    ports:
      - <span class="hljs-string">"3306:3306"</span>
    volumes:
      - db_data:/var/lib/mysql

volumes:
  db_data:
</code></pre>
<p>このファイルを作成したら、以下のコマンドでMySQLコンテナを起動できます。</p>
<pre><code class="hljs language-sh">docker-compose up -d
</code></pre>
<p>これで、MySQL環境のセットアップは完了です。</p>
