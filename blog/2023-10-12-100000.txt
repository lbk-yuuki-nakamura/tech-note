13:Ta87,<h1>TypeScript での安全な JSON パース</h1>
<p>JSON 文字列のパースは Web 開発の中で一般的なタスクの1つですが、不正な JSON 文字列や空文字を遭遇すると、エラーが発生することがあります。</p>
<p>この記事では、TypeScriptを使用してJSON文字列を安全にパースし、特定のエラーケースでデフォルト値を設定する方法を紹介します。</p>
<h1>問題点</h1>
<p><code>JSON.parse()</code> は、正しい JSON 文字列が与えられると期待されます。</p>
<p>しかし、与えられる文字列が空文字や不正な JSON の場合、エラーをスローします。</p>
<p>そのため、このようなエラーケースを適切に処理する必要があります。</p>
<h1>解決策</h1>
<p>以下のステップで、安全にJSONをパースする方法を実装します。</p>
<ol>
<li>
<p><code>try-catch</code> ブロックを使用して <code>JSON.parse()</code> を呼び出します。</p>
</li>
<li>
<p>文字列が空の場合や、パースした結果が配列でない場合、エラーをスローします。</p>
</li>
<li>
<p><code>catch</code> ブロックで、エラーが発生した場合のデフォルト値を設定します。</p>
</li>
</ol>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">let</span> <span class="hljs-attr">a</span>: string[];

<span class="hljs-keyword">try</span> {
  <span class="hljs-keyword">if</span> (hoge === <span class="hljs-string">''</span>) {
    a = [];
  } <span class="hljs-keyword">else</span> {
    a = <span class="hljs-title class_">JSON</span>.<span class="hljs-title function_">parse</span>(hoge);
    <span class="hljs-keyword">if</span> (!<span class="hljs-title class_">Array</span>.<span class="hljs-title function_">isArray</span>(a)) {
      <span class="hljs-keyword">throw</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">Error</span>(<span class="hljs-string">'Parsed value is not an array.'</span>);
    }
  }
} <span class="hljs-keyword">catch</span> (error) {
  a = [];
}

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(a);
</code></pre>
<p>この方法を使用することで、不正な JSON 文字列や空文字の場合でも、エラーを防ぐことができます。</p>
<h1>まとめ</h1>
<p>TypeScript を使用して、安全に JSON 文字列をパースし、特定のエラーケースでデフォルト値を設定する方法を紹介しました。</p>
