13:T1358,<h1>Zodを使用してKnex.jsクエリのレスポンスを型安全に検証する</h1>
<p>Knex.jsを使用してデータベースから情報を取得する際、レスポンスの形状や内容が期待通りであることを確認したい場面があります。</p>
<p>この記事では、Zodを使用してKnex.jsのレスポンスを型安全に検証する方法を解説します。</p>
<h1>必要なパッケージのインストール</h1>
<p>初めに、必要なパッケージをインストールします。</p>
<p>Knex.jsとZodをそれぞれインストールします。</p>
<pre><code class="hljs language-sh">npm install knex zod
</code></pre>
<h1>Knex.jsクエリの作成</h1>
<p><code>users</code> テーブルと <code>orders</code> テーブルを左結合して、それぞれのテーブルから特定のカラムを選択します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">const</span> knex = <span class="hljs-built_in">require</span>(<span class="hljs-string">'knex'</span>)({
  <span class="hljs-attr">client</span>: <span class="hljs-string">'pg'</span>,
  <span class="hljs-attr">connection</span>: {
    host : <span class="hljs-string">'127.0.0.1'</span>,
    user : <span class="hljs-string">'your_database_user'</span>,
    password : <span class="hljs-string">'your_database_password'</span>,
    database : <span class="hljs-string">'myapp_test'</span>
  }
});

<span class="hljs-title function_">knex</span>(<span class="hljs-string">'users'</span>)
  .<span class="hljs-title function_">leftJoin</span>(<span class="hljs-string">'orders'</span>, <span class="hljs-string">'users.id'</span>, <span class="hljs-string">'orders.user_id'</span>)
  .<span class="hljs-title function_">select</span>(<span class="hljs-string">'users.id as user_id'</span>, <span class="hljs-string">'users.name'</span>, <span class="hljs-string">'orders.id as order_id'</span>, <span class="hljs-string">'orders.hoge'</span>)
  .<span class="hljs-title function_">then</span>(<span class="hljs-function"><span class="hljs-params">data</span> =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(data);

    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">error</span>(err);
  });
</code></pre>
<h1>Zodスキーマの定義</h1>
<p>次に、上記のクエリのレスポンスに対応するZodのスキーマを定義します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">import</span> { z } <span class="hljs-keyword">from</span> <span class="hljs-string">'zod'</span>;

<span class="hljs-keyword">const</span> userOrderSchema = z.<span class="hljs-title function_">object</span>({
  <span class="hljs-attr">user_id</span>: z.<span class="hljs-title function_">number</span>(),
  <span class="hljs-attr">name</span>: z.<span class="hljs-title function_">string</span>(),
  <span class="hljs-attr">order_id</span>: z.<span class="hljs-title function_">number</span>(),
  <span class="hljs-attr">hoge</span>: z.<span class="hljs-title function_">string</span>()
});
</code></pre>
<h1>データの検証</h1>
<p>取得したデータが期待する形状かどうかをZodを使って検証します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">const</span> sampleData = [
  { <span class="hljs-attr">user_id</span>: <span class="hljs-number">1</span>, <span class="hljs-attr">name</span>: <span class="hljs-string">'Alice'</span>, <span class="hljs-attr">order_id</span>: <span class="hljs-number">101</span>, <span class="hljs-attr">hoge</span>: <span class="hljs-string">'value1'</span> },

<span class="hljs-comment">// データの検証</span>
<span class="hljs-keyword">const</span> parsedData = userOrderSchema.<span class="hljs-title function_">array</span>().<span class="hljs-title function_">parse</span>(sampleData);

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(parsedData);  <span class="hljs-comment">// 検証が成功した場合、元のデータがそのまま返されます</span>

<p>この方法を使用することで、Knex.jsから取得したデータが正しい形状であることを確認することができます。</p>
