13:Tc6f,<h1>knex.jsでのLEFT JOINの使用方法</h1>
<p><code>knex.js</code>は人気のあるSQLクエリビルダーで、多くのデータベースに対して統一された方法でクエリを作成することができます。</p>
<p>この記事では、<code>knex.js</code>を使用して<code>leftJoin</code>クエリを作成する方法について説明します。</p>
<h1>基本的なLEFT JOIN</h1>
<p>最も基本的な<code>leftJoin</code>の使用方法を以下に示します。</p>
<p>この例では、<code>users</code>テーブルと<code>orders</code>テーブルをLEFT JOINします。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">const</span> knex = <span class="hljs-built_in">require</span>(<span class="hljs-string">'knex'</span>)({
  <span class="hljs-attr">client</span>: <span class="hljs-string">'pg'</span>,
  <span class="hljs-attr">connection</span>: {
    <span class="hljs-comment">// データベース接続情報をこちらに設定</span>
  }
});

<span class="hljs-title function_">knex</span>(<span class="hljs-string">'users'</span>)
  .<span class="hljs-title function_">leftJoin</span>(<span class="hljs-string">'orders'</span>, <span class="hljs-string">'users.id'</span>, <span class="hljs-string">'orders.user_id'</span>)
  .<span class="hljs-title function_">select</span>(<span class="hljs-string">'users.*'</span>, <span class="hljs-string">'orders.order_number'</span>)
  .<span class="hljs-title function_">then</span>(<span class="hljs-function"><span class="hljs-params">data</span> =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(data);
  })
  .<span class="hljs-title function_">catch</span>(<span class="hljs-function"><span class="hljs-params">err</span> =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">error</span>(err);
  });
</code></pre>
<p>上記のクエリは、<code>users</code>テーブルのすべてのレコードと、関連する<code>orders</code>の<code>order_number</code>（もしあれば）を取得します。</p>
<p>関連する<code>orders</code>がない<code>user</code>は、<code>order_number</code>が<code>null</code>として返されます。</p>
<h1>メソッドの解説</h1>
<ul>
<li>
<p><code>.leftJoin()</code>: このメソッドは、LEFT JOINを行うためのメソッドです。最初の引数は結合するテーブルの名前、次の2つの引数は結合条件として使用するカラム名を示します。</p>
</li>
<li>
<p><code>.select()</code>: 取得するカラムを指定するためのメソッドです。この例では、<code>users</code>テーブルのすべてのカラムと<code>orders</code>テーブルの<code>order_number</code>カラムを取得しています。</p>
</li>
</ul>
