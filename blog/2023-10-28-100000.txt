13:T9c3,<h1>TypeScriptにおけるZodライブラリを使用した日付バリデーション</h1>
<p>TypeScriptでZodライブラリを使用する際、日付フィールドが <code>null</code> を許容するようにする方法について説明します。</p>
<h1>問題</h1>
<p>次のようなZodスキーマがあります</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-attr">create_date</span>: z.<span class="hljs-title function_">date</span>().<span class="hljs-title function_">optional</span>(),
</code></pre>
<p>このスキーマは <code>create_date</code> が省略可能であることを意味しますが、フィールドが <code>null</code> として明示された場合にはエラーが発生します。</p>
<p>エラーメッセージは以下のようになります</p>
<pre><code class="hljs language-sh">ZodError: [
  {
    <span class="hljs-string">"code"</span>: <span class="hljs-string">"invalid_type"</span>,
    <span class="hljs-string">"expected"</span>: <span class="hljs-string">"date"</span>,
    <span class="hljs-string">"received"</span>: <span class="hljs-string">"null"</span>,
    <span class="hljs-string">"path"</span>: [
      <span class="hljs-string">"create_date"</span>
    ],
    <span class="hljs-string">"message"</span>: <span class="hljs-string">"Expected date, received null"</span>
  }
]
</code></pre>
<h1>解決策</h1>
<p><code>null</code> 値も許容するためには <code>.nullable()</code> メソッドを使用します。</p>
<p>以下のようにスキーマを変更します</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-attr">create_date</span>: z.<span class="hljs-title function_">date</span>().<span class="hljs-title function_">optional</span>().<span class="hljs-title function_">nullable</span>(),
</code></pre>
<p>この変更により、 <code>create_date</code> は <code>undefined</code>、有効な日付、または <code>null</code> のいずれかを受け入れるようになります。</p>
<p>これは、オプションの日付フィールドが <code>null</code> を含むことが許可される典型的なケースです。</p>
