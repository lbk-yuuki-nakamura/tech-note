13:T136e,<h1>Knexで外部キー制約のあるテーブルからデータを削除する方法</h1>
<p>Knexを使用してデータベースの操作を行う際、外部キー制約があるテーブルからデータを削除することは、少し複雑になることがあります。</p>
<p>特に、他のテーブルがそのテーブルのデータを参照している場合、直接削除を試みると外部キー制約に違反してしまいます。</p>
<p>ここでは、そうした状況における対応策について説明します。</p>
<h1>シナリオ</h1>
<p>以下のような2つのテーブルがあるとします。</p>
<ul>
<li>
<p>Aテーブル: BテーブルのIDを外部キー(<code>b_id</code>)として持っています。このカラムは<code>notNullable</code>です。</p>
</li>
<li>
<p>Bテーブル: 削除したいデータを含んでいます。</p>
</li>
</ul>
<p>ただし、Aテーブルの外部キーである<code>b_id</code>は、<code>onDelete</code>が<code>NO ACTION</code>と設定されています。</p>
<p>この状態では、Bテーブルのデータを直接削除することはできません。</p>
<h1>解決策</h1>
<p>以下のステップで解決策を実行します。</p>
<h1>ステップ1: 外部キー制約の変更</h1>
<p>まず、Aテーブルの外部キーを一時的にnullableに変更し、その後外部キー制約を変更します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-comment">// Aテーブルの外部キーをnullableに変更</span>
<span class="hljs-keyword">await</span> knex.<span class="hljs-property">schema</span>.<span class="hljs-title function_">alterTable</span>(<span class="hljs-string">'A'</span>, <span class="hljs-function"><span class="hljs-params">table</span> =></span> {
  table.<span class="hljs-title function_">integer</span>(<span class="hljs-string">'b_id'</span>).<span class="hljs-title function_">nullable</span>().<span class="hljs-title function_">alter</span>();
});

<span class="hljs-comment">// 外部キー制約の変更</span>
<span class="hljs-keyword">await</span> knex.<span class="hljs-property">schema</span>.<span class="hljs-title function_">alterTable</span>(<span class="hljs-string">'A'</span>, <span class="hljs-function"><span class="hljs-params">table</span> =></span> {
  table.<span class="hljs-title function_">dropForeign</span>([<span class="hljs-string">'b_id'</span>]); <span class="hljs-comment">// 現在の外部キー制約を削除</span>
  table.<span class="hljs-title function_">foreign</span>(<span class="hljs-string">'b_id'</span>).<span class="hljs-title function_">references</span>(<span class="hljs-string">'B.id'</span>).<span class="hljs-title function_">onDelete</span>(<span class="hljs-string">'SET NULL'</span>); <span class="hljs-comment">// 新しい制約を設定</span>
});
</code></pre>
<h1>ステップ2: Aテーブルのデータ更新</h1>
<p>AテーブルのBテーブルに対する参照を更新します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-comment">// Aテーブルのb_idをnullに設定する</span>
<span class="hljs-keyword">await</span> <span class="hljs-title function_">knex</span>(<span class="hljs-string">'A'</span>).<span class="hljs-title function_">update</span>({ <span class="hljs-attr">b_id</span>: <span class="hljs-literal">null</span> });
</code></pre>
<h1>ステップ3: Bテーブルのデータ削除</h1>
<p>Aテーブルからの参照が更新されたので、Bテーブルのデータを安全に削除できます。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">await</span> <span class="hljs-title function_">knex</span>(<span class="hljs-string">'B'</span>).<span class="hljs-title function_">delete</span>();
</code></pre>
<h1>ステップ4: 後片付け</h1>
<p>Aテーブルのカラムを元の状態（<code>notNullable</code>）に戻します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">await</span> knex.<span class="hljs-property">schema</span>.<span class="hljs-title function_">alterTable</span>(<span class="hljs-string">'A'</span>, <span class="hljs-function"><span class="hljs-params">table</span> =></span> {
  table.<span class="hljs-title function_">integer</span>(<span class="hljs-string">'b_id'</span>).<span class="hljs-title function_">notNullable</span>().<span class="hljs-title function_">alter</span>();
});
</code></pre>
<h1>まとめ</h1>
<p>外部キー制約を持つテーブルからのデータ削除は、直感的でない場合があります。</p>
<p>しかし、適切なステップを踏むことで、データベースの整合性を保ちながら安全に操作を行うことができます。</p>
