<p>プロジェクトにPlaywrightをインストールするには、次のコマンドを実行します。</p>
<pre><code class="hljs language-sh">npm install playwright
</code></pre>

<p>Playwrightを使用してテストを書きます。

<pre><code class="hljs language-JavaScript"><span class="hljs-keyword">import</span> { test, expect } <span class="hljs-keyword">from</span> <span class="hljs-string">'@playwright/test'</span>;
