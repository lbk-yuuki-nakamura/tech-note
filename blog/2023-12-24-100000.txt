13:Td6b,<h1>Knex.jsの環境構築ガイド</h1>
<p>この記事では、Node.js用の強力なSQLクエリビルダーであるKnex.jsの環境構築方法について解説します。
Knex.jsは、MySQL、PostgreSQL、SQLite3など、多くのSQLデータベースとの接続をサポートしています。</p>
<h2>ステップ1: Node.jsのインストール</h2>
<p>Knex.jsを使用する前に、Node.jsがシステムにインストールされていることを確認してください。
Node.jsは以下の公式ウェブサイトからダウンロードできます：<a href="https://nodejs.org/">Node.js公式サイト</a></p>
<h2>ステップ2: 新しいNode.jsプロジェクトの作成</h2>
<p>新しいディレクトリを作成し、その中で以下のコマンドを実行してNode.jsプロジェクトを初期化します。</p>
<pre><code class="hljs language-sh">npm init -y
</code></pre>
<h2>ステップ3: Knex.jsとデータベースドライバのインストール</h2>
<p>次に、Knex.jsと使用するデータベースに対応するドライバをインストールします。
例えば、PostgreSQLを使用する場合は以下のようになります。</p>
<pre><code class="hljs language-sh">npm install knex pg
</code></pre>
<p>MySQLやSQLiteを使用する場合は、それぞれ<code>mysql</code>や<code>sqlite3</code>をインストールしてください。</p>
<h2>ステップ4: Knexfileの設定</h2>
<p>プロジェクトのルートに<code>knexfile.js</code>を作成し、データベースの設定を記述します。
以下はPostgreSQL用の設定例です。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-variable language_">module</span>.<span class="hljs-property">exports</span> = {
  <span class="hljs-attr">development</span>: {
    <span class="hljs-attr">client</span>: <span class="hljs-string">'postgresql'</span>,
    <span class="hljs-attr">connection</span>: {
      <span class="hljs-attr">database</span>: <span class="hljs-string">'my_db'</span>,
      <span class="hljs-attr">user</span>:     <span class="hljs-string">'username'</span>,
      <span class="hljs-attr">password</span>: <span class="hljs-string">'password'</span>
    },
    <span class="hljs-attr">migrations</span>: {
      <span class="hljs-attr">tableName</span>: <span class="hljs-string">'knex_migrations'</span>
    }
  }
};
</code></pre>
<h2>ステップ5: マイグレーションとシードの使用</h2>
<p>データベーススキーマの作成や初期データの投入には、Knexのマイグレーションとシード機能を使用します。</p>
<ul>
<li>マイグレーションの作成：</li>
</ul>
<pre><code class="hljs language-sh">npx knex migrate:make migration_name
</code></pre>
<ul>
<li>マイグレーションの実行：</li>
</ul>
<pre><code class="hljs language-sh">npx knex migrate:latest
</code></pre>
<ul>
<li>シードファイルの作成：</li>
</ul>
<pre><code class="hljs language-sh">npx knex seed:make seed_name
</code></pre>
<ul>
<li>シードの実行：</li>
</ul>
<pre><code class="hljs language-sh">npx knex seed:run
</code></pre>
<p>以上で基本的なKnex.jsの環境構築は完了です。
プロジェクトやデータベースに応じて設定を調整してください。
