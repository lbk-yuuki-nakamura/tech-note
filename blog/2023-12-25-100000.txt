13:Te3d,<h1>Knex.jsで外部結合を行う方法</h1>
<p>Knex.jsは、Node.jsのための強力なクエリビルダーライブラリです。
SQLクエリを直接書くことなく、JavaScriptのコードでデータベース操作ができるように設計されています。
この記事では、Knexを使用して外部結合（OUTER JOIN）を行う方法について説明します。</p>
<h2>基本的な外部結合の例</h2>
<p>Knexを使用して、2つのテーブル間で外部結合を行う基本的な方法を以下に示します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-title function_">knex</span>(<span class="hljs-string">'table1'</span>)
  .<span class="hljs-title function_">leftJoin</span>(<span class="hljs-string">'table2'</span>, <span class="hljs-string">'table1.column1'</span>, <span class="hljs-string">'table2.column2'</span>)
  .<span class="hljs-title function_">select</span>(<span class="hljs-string">'*'</span>)
  .<span class="hljs-title function_">then</span>(<span class="hljs-function"><span class="hljs-params">rows</span> =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(rows);
  })
  .<span class="hljs-title function_">catch</span>(<span class="hljs-function"><span class="hljs-params">error</span> =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">error</span>(error);
  });
</code></pre>
<p>この例では、<code>table1</code> と <code>table2</code> を結合し、<code>table1</code>の<code>column1</code>と<code>table2</code>の<code>column2</code>が一致する行を取得しています。
<code>leftJoin</code>メソッドは左外部結合を実行し、<code>table1</code>の全ての行と、一致する<code>table2</code>の行を取得します。</p>
<h2>右外部結合</h2>
<p>右外部結合を行う場合は、<code>rightJoin</code>メソッドを使用します。
以下に例を示します。</p>
<pre><code class="hljs language-JavaScript"><span class="hljs-title function_">knex</span>(<span class="hljs-string">'table1'</span>)
  .<span class="hljs-title function_">rightJoin</span>(<span class="hljs-string">'table2'</span>, <span class="hljs-string">'table1.column1'</span>, <span class="hljs-string">'table2.column2'</span>)
  .<span class="hljs-title function_">select</span>(<span class="hljs-string">'*'</span>)
  .<span class="hljs-title function_">then</span>(<span class="hljs-function"><span class="hljs-params">rows</span> =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(rows);
  })
  .<span class="hljs-title function_">catch</span>(<span class="hljs-function"><span class="hljs-params">error</span> =></span> {
    <span class="hljs-variable language_">console</span>.<span class="hljs-title function_">error</span>(error);
  });
</code></pre>
<p>この場合、<code>table2</code>の全ての行と、一致する<code>table1</code>の行が取得されます。</p>
<h2>注意点</h2>
<p>フルアウタージョイン（full outer join）はKnexでは直接サポートされていません。
このため、異なる方法（例えば、複数のクエリを組み合わせる）を検討する必要があります。</p>
<p>また、特定の列だけを選択することも可能です。
例えば、<code>select('table1.column1', 'table2.column2')</code>のように指定できます。</p>
