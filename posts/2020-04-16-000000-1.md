# ◾️NSStringクラス

Swiftでも、[Objective-C](http://d.hatena.ne.jp/keyword/Objective-C)で使用されていた「NSString」クラスを使用する事が可能である。
NSStringクラスは[Objective-C](http://d.hatena.ne.jp/keyword/Objective-C)のクラスの為、[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)の最上行に「import UIKit」を追加する必要がある。

（記載ルール）

```swift
let 定数名:NSString = "値"
```

（例）

```swift
let str:NSString = "こんにちは"
```

NSString型とString型は相互変換可能である。
相互変換するには次のように「変数名 as String」を使用する。

[NSString型→String型]
（記載ルール）

```swift
let 定数名1:NSString = "値"
let 定数名2:String = 定数名1 as String
```

（例）

```swift
let str:NSString = "こんにちは"
let str1:String = str as String
```

[String型→NSString型]
（記載ルール）

```swift
let 定数名1:String = "値"
let 定数名2:NSString = 定数名1 as String
```

（例）

```swift
let str:String = "こんにちは"
let str1:NSString = str as NSString
```
