# ◾️浮動小数点型

浮動小数点型は、小数点以下の値を持つ数値を表すための型である。
SwiftではDouble型とFloat型の2種類が用意されている。

型宣言なしの型推論で宣言するとDouble型になる。

[Double型]
（記載ルール）

let 定数名 = 浮動少数点型の値

（例）

```swift
let num = 3.14
```

Float型の変数を宣言するには、明示的に型を指定する必要がある。

[Float型]
（記載ルール）

let 定数名:Float = 浮動少数点型の値

（例）

```swift
let num:Float = 3.14
```
