# ◾️配列

配列とは、複数のデータを1つの変数で管理できる入れ物の事である。
データを入れるための箱が番号付きで並べられていて、その中にデータを入れていくイメージである。
箱の中に入れたデータを差し替えたり、箱を追加、削除する事もできる。
※「var（変数）」で宣言した配列は要素の変更が可能だが、「let（定数）」で宣言した配列は変更できない。

配列は以下のコードのように[値, 値, 値,…]で作る。
型を指定しなければ、型の種類を混在させて格納できる。

[[型推論](http://d.hatena.ne.jp/keyword/%B7%BF%BF%E4%CF%C0)]
（記載ルール）

```swift
var 変数名 = [データ, データ, データ、、、]
```

（例）

```swift
var array = ["データ1", "データ2", "データ3"]
```

[データ型指定]
（記載ルール）

```swift
var 変数名:[データ型] = [データ, データ, データ、、、]
```

（例）

```swift
var array:[String] = ["データ1", "データ2", "データ3"]
```

空の配列を作るには以下のコード様にする。

[[型推論](http://d.hatena.ne.jp/keyword/%B7%BF%BF%E4%CF%C0)]
（記載ルール）

```swift
var 変数名 = [AnyObject]()
```

（例）

```swift
var array = [AnyObject]()
```

[データ型指定]
（記載ルール）

```swift
var 変数名 = [データ型]()
```

（例）

```swift
var array = [String]()
```
