# ◾️配列のその他のプロパティ、便利な使用方法

以下によく使用する配列のプロパティと、便利な使用方法を記載する。

[配列の指定indexの要素を取得する]

```swift
配列の変数名[index番号]
```

[最初の要素を取得する]

```swift
配列の変数名.first!
```

[最後の要素を取得する]

```swift
配列の変数名.last!
```

[配列の先頭を削除する]

```swift
配列の変数名.removeFirst()
```

[配列の末尾を削除する]

```swift
配列の変数名.removeLast()
```

[配列の指定indexを削除する]

```swift
配列の変数名.remove(at: index番号)
```

[配列の全要素を削除する]

```swift
配列の変数名.removeAll()
```

[配列が空かチェック(空の場合は「true」)]

```swift
配列の変数名.isEmpty
```

配列の要[素数を取得]

```swift
配列の変数名.count
```

[配列の中身を表示]

```swift
配列の変数名.description
```

[配列の要素分のループ]

```swift
for 変数A in 配列の変数名 {
}
```

[配列の後ろに要素を1つ追加する]

```swift
配列の変数名.append(追加する値)
```

[任意の位置に要素を追加する]

```swift
配列の変数名.insert(追加する値, at:index番号)
```

[配列の結合]

```swift
配列の変数名 + 追加する配列の変数名
```

[任意の位置に配列を追加する]

```swift
配列の変数名.insert(contentsOf: 追加する配列の変数名, at: index番号)
```
