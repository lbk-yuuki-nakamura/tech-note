# ◾️while

「while」文とは条件が真の場合に処理を繰り返すループ処理である。
指定した条件に達するまで、ずっとループを繰り返す場合などに使用する。
※指定した条件に達する事がない場合、無限ループに陥る事がある為、注意が必要である。

（記載ルール）

```swift
while (ループ条件) {
    // 処理
}
```

（例）

```swift
var num = 0
while(num < 10) {
    print(num)
    num += 1
}
```

# ◾️repeat while

「repeat while」は、最初に処理を実行した後で指定したループ条件をチェックし、満たしている間はループを行う。
while文と違い、最低でも1回は処理が行われる。

（記載ルール）

```swift
repeat {
    // 処理
} while (ループ条件)
```

（例）

```swift
var num = 0
repeat {
    print(num)
    num += 1
} while(num > 10)
```
