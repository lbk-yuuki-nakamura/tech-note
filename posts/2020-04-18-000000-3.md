# ◾️for in文

「for in」文とは条件が真の場合に処理を繰り返すループ処理である。
指定した回数分、ループで処理を繰り返したい時などに使用する。

昇順ループの場合には、以下の様に記載する。

（記載ルール）

```swift
for 変数 in 開始値 ..< 終了値 {
    // 処理
}
```

（例）

```swift
for num in 0 ..< 10 {
    print(num)
}
```

降順ループの場合には、以下の様に記載する。（reversedを使用する）

（記載ルール）

```swift
for 変数 in (開始値 ..< 終了値).reversed() {
    // 処理
}
```

（例）

```swift
for num in (0 ..< 10).reversed() {
    print(num)
}
```
