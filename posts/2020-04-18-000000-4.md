# ◾️if文

if文とは、条件分岐処理で使用される構文である。
条件分岐とは、「〜の場合は〜をするが、〜の場合には〜をする。」という様に状況によって処理を変える方法である。

（記載ルール）

```swift
if 条件式 {
    条件式が真（true）の場合の処理
}
```

（例）

```swift
if 1 < 2 {
    print("true")
}
```

「条件式が真（true）の場合、偽(false)の場合」で処理を分ける事ができる。

（記載ルール）

```swift
if 条件式 {
    条件式が真（true）の場合の処理
} else {
    条件式が偽（false）の場合の処理
}
```

（例）

```swift
if 1 < 3 {
    print("true")
} else {
    print("else")
}
```

「複数の条件を指定」を行うこともできる。（「else if」を使用する）

（記載ルール）

```swift
if 条件式1 {
    条件式1が真（true）の場合の処理
} else if 条件式2 {
    条件式2が真（true）の場合の処理
} else {
    どの条件にも一致しなかった場合に実行する処理
}
```

（例）

```swift
if 1 < 2 {
    print("true")
} else if 1 < 3 {
    print("else if")
} else {
    print("else")
}
```

条件式には、「比較[演算子](http://d.hatena.ne.jp/keyword/%B1%E9%BB%BB%BB%D2)」「論理[演算子](http://d.hatena.ne.jp/keyword/%B1%E9%BB%BB%BB%D2)」などで条件式を記載する。
※比較[演算子](http://d.hatena.ne.jp/keyword/%B1%E9%BB%BB%BB%D2)と論理[演算子](http://d.hatena.ne.jp/keyword/%B1%E9%BB%BB%BB%D2)に関しては、【比較[演算子](http://d.hatena.ne.jp/keyword/%B1%E9%BB%BB%BB%D2)】【論理[演算子](http://d.hatena.ne.jp/keyword/%B1%E9%BB%BB%BB%D2)】で説明する。
