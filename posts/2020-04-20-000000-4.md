# ◾️引数

引数（ひきすう）とは、関数に値を渡す方法である。
※引数は「,」で区切る事で複数指定する事が可能である。

以下の様に記載する。

（記載ルール）

```swift
func 関数名(関数内で使用する変数名:データ型, 、、、){
    // 関数の中の処理
}
```

（例）

```swift
func kansu(str:String){
    print("引数は\(str)である")
}
```

引数を利用する際の呼び出しは以下の様に呼び出す。

（記載ルール）

```swift
呼び出したい関数名(関数内で使用する変数名:渡したい値, 、、、)
```

（例）

```swift
kansu(str: "hikisuu")
```

関数の呼び出し時に記載する「関数内で使用する変数名」を省略する事ができる。
省略する為には、以下の様に関数を定義する必要がある。
※「関数内で使用する変数名」の前にスペースを開けて「_」を記載する事で省略ができる。

（記載ルール）

```swift
func 関数名(_ 関数内で使用する変数名:データ型, 、、、){
    // 関数の中の処理
}
```

（例）

```swift
func kansu(_ str:String){
    print("引数は\(str)である")
}
```

引数を利用する際の呼び出しは以下の様に呼び出す。

（記載ルール）

```swift
呼び出したい関数名(渡したい値, 、、、)
```

（例）

```swift
kansu("hikisuu")
```
