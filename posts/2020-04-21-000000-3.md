# ◾️オーバーライド

クラスを継承したが、あるメソッドは、[スーパークラス](http://d.hatena.ne.jp/keyword/%A5%B9%A1%BC%A5%D1%A1%BC%A5%AF%A5%E9%A5%B9)のメソッドではなく、サブクラスのメソッドを使用したい場合がある。
そのようなときは、以下のコードのようにoverrideを先頭に書いてメソッドを定義することで、[スーパークラス](http://d.hatena.ne.jp/keyword/%A5%B9%A1%BC%A5%D1%A1%BC%A5%AF%A5%E9%A5%B9)の関数を上書きできる。
これをオーバーライドという。
※メソッド名、引数、戻り値などで相違する点がある場合には[コンパイル](http://d.hatena.ne.jp/keyword/%A5%B3%A5%F3%A5%D1%A5%A4%A5%EB)エラーが発生する。

```swift
class サブクラス名：スーパークラス名 {
    プロパティ
    メソッド
    override func スーパークラスと同じメソッド名(){
        // 新しい処理
    }
}
```

# ◾️スーパークラスのメソッドの呼び出し

[スーパークラス](http://d.hatena.ne.jp/keyword/%A5%B9%A1%BC%A5%D1%A1%BC%A5%AF%A5%E9%A5%B9)のメソッドをオーバーライドしたけど、オーバーライド前の[スーパークラス](http://d.hatena.ne.jp/keyword/%A5%B9%A1%BC%A5%D1%A1%BC%A5%AF%A5%E9%A5%B9)のメソッドを呼び出したいときがある。
そんなときは、以下の様にsuperに対してオーバーライドしたメソッドを呼び出す。
superとは[スーパークラス](http://d.hatena.ne.jp/keyword/%A5%B9%A1%BC%A5%D1%A1%BC%A5%AF%A5%E9%A5%B9)の事を意味している。
メソッドをオーバーライドしても[スーパークラス](http://d.hatena.ne.jp/keyword/%A5%B9%A1%BC%A5%D1%A1%BC%A5%AF%A5%E9%A5%B9)のメソッドが完全に消えてしまうわけでは無い。

```swift
class サブクラス名：スーパークラス名 {
    プロパティ
    メソッド
    override func スーパークラスと同じメソッド名(){
        // 新しい処理
        super.スーパークラスと同じメソッド名()
    }
}
```
