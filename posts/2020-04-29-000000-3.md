## ◾️はじめに

「[SwiftUIのプロジェクト作成](http://developer-kuro.com/develop/2019/08/20/swiftui-create-project/)」の記事で紹介しているSwiftUIのプロジェクトを作成できる前提とします。（作成方法がわからない場合は「[SwiftUIのプロジェクト作成](http://developer-kuro.com/develop/2019/08/20/swiftui-create-project/)」の記事を参照してください。）

## ■SwiftUIで地図の詳細を表示する

1.プロジェクトの[ディレクト](http://d.hatena.ne.jp/keyword/%A5%C7%A5%A3%A5%EC%A5%AF%A5%C8)リを右クリックし、「New File...」を押下する。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707120559.png)

2.「SwiftUI View」を選択して、「Next」を押下する。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707120310.png)

3.適当な名前を入力し、「Create」を押下する。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707130334.png)

4.「[SwiftUIでMapKitを利用して地図を表示する](http://developer-kuro.com/develop/2019/08/29/swiftui-mapkit/)」の記事で紹介した地図の表示を「3」で作成したファイルに書き込む。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707130343.png)

5.「ContentView」に戻り、Textを「VStack」に入れる。（「[SwiftUIでTextを縦(VStack)に並べて複数表示する](http://developer-kuro.com/develop/2019/08/23/swiftui-text-vstack/)」を参照してください。）

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707120517.png)

6.Textの上の行に「3」で作成した「クラス名()」を記載する。（地図クラスの[インスタンス](http://d.hatena.ne.jp/keyword/%A5%A4%A5%F3%A5%B9%A5%BF%A5%F3%A5%B9)化）

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707130432.png)

7.「6」に以下の[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)を記載し、高さを設定する。（正常に地図が表示されることをプレビューで確認する）

```
.frame(height: 300)
```

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707120900.png)

8.「7」のしたの行に「[SwiftUIでImageを表示する](http://developer-kuro.com/develop/2019/08/27/swiftui-image/)」「[SwiftUIでImageを装飾する](http://developer-kuro.com/develop/2019/08/28/swiftui-image-custom/)」で作成した画像を作成する。（正常に画像が表示されることをプレビューで確認する）

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707120323.png)

9.以下の[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)を「8」の画像の下の行に記載し、画像を地図に被せる。

```
.offset(y: -130)
.padding(.bottom, -130)
```

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707120524.png)

10.以下の[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)を「VStack」の一番下に記載し、スペースを埋めて画像を画面上部に押し上げる。

```
Spacer()
```

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707120755.png)

11.以下の[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)を「Map」の下の行に記載し、セーフエリアを埋める。

```
.edgesIgnoringSafeArea(.top)
```

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220707/20220707130416.png)

これで、地図の詳細のような画面が作成できました！（画像はア[ヒル](http://d.hatena.ne.jp/keyword/%A5%D2%A5%EB)ですがw）

[Apple](http://d.hatena.ne.jp/keyword/Apple)様の[チュートリアル](http://d.hatena.ne.jp/keyword/%A5%C1%A5%E5%A1%BC%A5%C8%A5%EA%A5%A2%A5%EB)ではテキストの位置の微調整や画像が地図っぽい画像だったりしますが、概ねやっていることは同じです！
