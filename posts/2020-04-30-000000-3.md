# 以下の手順でWordpressをインストールする。

- ターミナルを起動し、[SSH](http://d.hatena.ne.jp/keyword/SSH)（以下のコマンド）でサーバーにアクセスする。

```
ssh root@[IP]
```

※上記の「[IP]」には自身のサーバーのIPを代入すること（以下のようになる）

```
ssh root@111.222.33.44
```

<hr class="wp-block-separator"/>

- [mariadb](http://d.hatena.ne.jp/keyword/mariadb)（[MySQL](http://d.hatena.ne.jp/keyword/MySQL)）をインストール

```
yum install mariadb mariadb-server
```

- DBの[自動起動](http://d.hatena.ne.jp/keyword/%BC%AB%C6%B0%B5%AF%C6%B0)設定

```
systemctl enable mariadb.service
```

- DB起動

```
systemctl start mariadb.service
```

- [MySQL](http://d.hatena.ne.jp/keyword/MySQL)にログイン

```sql
mysql -u root
```

- DBを作成

```sql
create database wordpress;
```

- rootのパスワードを設定

```sql
update mysql.user set password=password('password') where user = 'root';
```

- 設定を反映

```sql
flush privileges;
```

- [MySQL](http://d.hatena.ne.jp/keyword/MySQL)ログアウト

```sql
exit;
```

<hr class="wp-block-separator"/>

- [PHP](http://d.hatena.ne.jp/keyword/PHP)をインストール（[LAMP](http://d.hatena.ne.jp/keyword/LAMP)でインストールされているが、足りないモジュールがあるため）

```
yum -y install php
```

- ファイアーウォールを起動（CentOS7起動時には停止されている）

```
systemctl start firewalld
```

- ポート８０を開放

```
firewall-cmd --add-port=80/tcp --zone=public --permanent
```

- ファイアーウォールの再起動

```
firewall-cmd --reload
```

- [Apache](http://d.hatena.ne.jp/keyword/Apache)の起動

```
systemctl start httpd
```

- [Apache](http://d.hatena.ne.jp/keyword/Apache)のデーモン化（サーバー起動時に、[自動起動](http://d.hatena.ne.jp/keyword/%BC%AB%C6%B0%B5%AF%C6%B0)するように設定）

```
systemctl enable httpd
```

- [Apache](http://d.hatena.ne.jp/keyword/Apache)のルートに移動

```
cd /var/www/html/
```

- [Wordpress](http://d.hatena.ne.jp/keyword/Wordpress)をインストール（Zipをダウンロード）

```
wget https://ja.wordpress.org/wordpress-4.4.2-ja.zip
```

- [Wordpress](http://d.hatena.ne.jp/keyword/Wordpress)を解凍

```
unzip wordpress-4.4.2-ja.zip
```

- 権限を[Apache](http://d.hatena.ne.jp/keyword/Apache)で設定（「[wordpress](http://d.hatena.ne.jp/keyword/wordpress)」[ディレクト](http://d.hatena.ne.jp/keyword/%A5%C7%A5%A3%A5%EC%A5%AF%A5%C8)リに[Apache](http://d.hatena.ne.jp/keyword/Apache)でアクセスできるようにする）

```
chown -R apache. wordpress
```

- [Apache](http://d.hatena.ne.jp/keyword/Apache)の再起動

```
systemctl restart httpd
```
