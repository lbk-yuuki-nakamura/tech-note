## ■はじめに

本手順は、さくら[VPS](http://d.hatena.ne.jp/keyword/VPS)でサーバーを契約し、スタートアップ[スクリプト](http://d.hatena.ne.jp/keyword/%A5%B9%A5%AF%A5%EA%A5%D7%A5%C8)で「[LAMP](http://d.hatena.ne.jp/keyword/LAMP)」を選択し、インストールした後の手順を記載します。

## ■手順

ターミナルでさくら[VPS](http://d.hatena.ne.jp/keyword/VPS)に[SSH](http://d.hatena.ne.jp/keyword/SSH)接続する。

```
ssh root@[IPアドレス]
```

接続後、以下のコマンドをコピペして、実行する。

```
# ファイアーウォール の自動起動
systemctl enable firewalld
# ファイアーウォール の起動
systemctl start firewalld
# Apacheの起動
systemctl start httpd
# ファイアーウォール のHTTPの開通
firewall-cmd --add-service=http --zone=public --permanent
# ファイアーウォール のHTTPSの開通
firewall-cmd --add-service=https --zone=public --permanent
# ファイアーウォール の80番ポートの開通
firewall-cmd --add-port=80/tcp --permanent
# ファイアーウォール の再起動
systemctl restart firewalld
# Apacheの自動起動
systemctl enable httpd
```

その後、ブラウザで、以下のアドレスにアクセスして、[Apache](http://d.hatena.ne.jp/keyword/Apache)のサイトにつながればOKです！

http://[[IPアドレス](http://d.hatena.ne.jp/keyword/IP%A5%A2%A5%C9%A5%EC%A5%B9)]
