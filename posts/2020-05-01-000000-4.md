## ■はじめに

本記事は、SignalRを利用して、UWPのアプリから[WPF](http://d.hatena.ne.jp/keyword/WPF)のアプリのメソッドを実行する為の方法をまとめた記事の、[WPF](http://d.hatena.ne.jp/keyword/WPF)アプリの作成記事です。

## ■手順

[Visual Studio](http://d.hatena.ne.jp/keyword/Visual%20Studio)の新規プロジェクト作成より、「[WPF](http://d.hatena.ne.jp/keyword/WPF)　アプリ（[.NET Framework](http://d.hatena.ne.jp/keyword/.NET%20Framework)）」を選択し、「次へ」を押下する。

![](/images/2020-05-01-000000-4/20220707120117.png)

プロジェクト名に任意の名前を設定し、「作成」を押下する。

![](/images/2020-05-01-000000-4/20220707120121.png)

プロジェクトが起動したら、「ソリューション [エクスプローラ](http://d.hatena.ne.jp/keyword/%A5%A8%A5%AF%A5%B9%A5%D7%A5%ED%A1%BC%A5%E9)ー」のプロジェクト名を右クリックする。

![](/images/2020-05-01-000000-4/20220707140409.png)

右クリックで出てきたポップアップの「NuGet パッケージ管理」を選択する。

![](/images/2020-05-01-000000-4/20220707140412.png)

NuGetのウィンドウの「参照」を押下する。

![](/images/2020-05-01-000000-4/20220707115348.png)

検索項目に「[Microsoft](http://d.hatena.ne.jp/keyword/Microsoft).AspNet.SignalR.Core」を入力し、対象のパッケージを選択後、「インストール」ボタンを押下する。

※ライセンスの同意などを行い、NuGetがインストールされるのをまつ。

※「インストール」を押下場所が「アンインストール」に変われば、インストール成功です。

同様の手順で、以下のパッケージをインストールする。（一番上は、上記手順でインストールされているはずです。）

[Microsoft](http://d.hatena.ne.jp/keyword/Microsoft).AspNet.SignalR.Core
[Microsoft](http://d.hatena.ne.jp/keyword/Microsoft).AspNet.SignalR.SystemWeb
[Microsoft](http://d.hatena.ne.jp/keyword/Microsoft).Owin.Cors
[Microsoft](http://d.hatena.ne.jp/keyword/Microsoft).Owin.Hosting
[Microsoft](http://d.hatena.ne.jp/keyword/Microsoft).Owin.Host.HttpListener

![](/images/2020-05-01-000000-4/20220707120209.png)

![](/images/2020-05-01-000000-4/20220707140416.png)

「ソリューション [エクスプローラ](http://d.hatena.ne.jp/keyword/%A5%A8%A5%AF%A5%B9%A5%D7%A5%ED%A1%BC%A5%E9)ー」のプロジェクト名を右クリックし、「追加」内の「クラス」を選択する。

![](/images/2020-05-01-000000-4/20220707120126.png)

「クラス」が選択されている状態で、「名前」に「AppStartup.cs」を入力し、「追加」を押下する。

※同様の手順で、「SampleHub.cs」クラスも作成する。

![](/images/2020-05-01-000000-4/20220707120214.png)

出来上がった「AppStartup」クラスに以下を記載する。

```c#
using Microsoft.Owin.Cors;
using Owin;

namespace SignalRSampleServer
{
    class AppStartup
    {
        public void Configuration(IAppBuilder app)
        {
            app.UseCors(CorsOptions.AllowAll);
            app.MapSignalR("/device", new Microsoft.AspNet.SignalR.HubConfiguration());
        }
    }
}
```

出来上がった「SampleHub」クラスに以下を記載する。

```c#
using Microsoft.AspNet.SignalR;
using Microsoft.AspNet.SignalR.Hubs;

namespace SignalRSampleServer
{
    [HubName("Sample")]
    public class SampleHub : Hub
    {
        public void CallSample()
        {
            System.Diagnostics.Debug.WriteLine("=====SampleHubの呼び出す=====");
        }
    }
}
```

プロジェクト作成時に用意されていた、「MainWindow.[xaml](http://d.hatena.ne.jp/keyword/xaml)」を展開し、「MainWindow.[xaml](http://d.hatena.ne.jp/keyword/xaml).cs」を開き、以下になるように記載する。

※具体的には、「_startup」の[グローバル変数](http://d.hatena.ne.jp/keyword/%A5%B0%A5%ED%A1%BC%A5%D0%A5%EB%CA%D1%BF%F4)の追加と、「MainWindow」のコンスト[ラク](http://d.hatena.ne.jp/keyword/%A5%E9%A5%AF)タ内で、ローカルホストの起動を追加しています。

![](/images/2020-05-01-000000-4/20220707140419.png)

```c#
using Microsoft.Owin.Hosting;
using System;
using System.Windows;

namespace SignalRSampleServer
{
    /// <summary>
    /// MainWindow.xaml の相互作用ロジック
    /// </summary>
    public partial class MainWindow : Window
    {

        private IDisposable _startup;

        public MainWindow()
        {
            InitializeComponent();
            _startup = WebApp.Start<AppStartup>("http://localhost:8080");
        }
    }
}
```
