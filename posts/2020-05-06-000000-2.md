## ■問題

強制アップデートなどで、「`https://itunes.apple.com/lookup?id=[AppID]`」の[API](http://d.hatena.ne.jp/keyword/API)を使用してバージョンを取得することがあります。

しかし、実際に[API](http://d.hatena.ne.jp/keyword/API)を実行しても以下のレスポンスが返ってきました。

```
{
 "resultCount":0,
 "results": []
}
```

## ■原因

アプリのリリース国に「[アメリ](http://d.hatena.ne.jp/keyword/%A5%A2%A5%E1%A5%EA)カ」が含まれていない場合に、上記のレスポンスが返ってくるようです。

対応としては、[API](http://d.hatena.ne.jp/keyword/API)のURLに国の情報を入れることで正しく返ってきます。

```
【URL】
https://itunes.apple.com/[国コード]/lookup?id=[AppID]

【例（日本の場合）】
https://itunes.apple.com/jp/lookup?id=[AppID]
```
