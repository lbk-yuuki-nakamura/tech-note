## ■はじめに

サーバーで、指定の[ディレクト](http://d.hatena.ne.jp/keyword/%A5%C7%A5%A3%A5%EC%A5%AF%A5%C8)リ配下の「〜」を含むファイル名を検索したい場合があります。

ここでは、findコマンドを使用して、上記の要件を満たすコマンドを記載します。

## ■手順

以下のコマンドが[ディレクト](http://d.hatena.ne.jp/keyword/%A5%C7%A5%A3%A5%EC%A5%AF%A5%C8)リ配下のファイル名検索です。

[ファイル名]の部分に任意のファイル名を記載してください。

```bash
【コマンド】
$ find ./ -name "*[ファイル名]*" -type f

【例】
$ find ./ -name "*index*" -type f
```
