## ■はじめに

サーバーで、指定のディレクトリ配下の「〜」を含むファイル名を検索したい場合があります。

ここでは、findコマンドを使用して、上記の要件を満たすコマンドを記載します。

## ■手順

以下のコマンドがディレクトリ配下のファイル名検索です。

[ファイル名]の部分に任意のファイル名を記載してください。

```bash
【コマンド】
$ find ./ -name "*[ファイル名]*" -type f

【例】
$ find ./ -name "*index*" -type f
```
