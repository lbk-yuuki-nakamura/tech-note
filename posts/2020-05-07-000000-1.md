## ■はじめに

ここでは、[Python](http://d.hatena.ne.jp/keyword/Python)と[OpenCV](http://d.hatena.ne.jp/keyword/OpenCV)を使用して画像解析を行うための環境構築手順を記載します。

[Mac](http://d.hatena.ne.jp/keyword/Mac)を前提として記載します。

## ■手順

ターミナルで以下のコマンドを実行し、「[Xcode](http://d.hatena.ne.jp/keyword/Xcode) Command Line Tools」をインストールします。

```
xcode-select --install
```

[こちら](https://brew.sh/)のサイトから、「/usr/bin/[ruby](http://d.hatena.ne.jp/keyword/ruby)」で始まるコマンドを丸々コピーして、ターミナルで実行し、「Homebrew」をインストールします。

ターミナルで以下のコマンドを実行し、「pyenv」をインストールします。

```
brew install pyenv
```

ターミナルで以下のコマンドを実行し、「pyenv-virtualenv」をインストールします。

```
brew install pyenv-virtualenv
```

ターミナルで以下のコマンドを実行し、インストールできる[Python](http://d.hatena.ne.jp/keyword/Python)のバージョンを確認します。

```
pyenv install -l
```

ターミナルで以下のコマンドを実行し、「[Python](http://d.hatena.ne.jp/keyword/Python)」をインストールします。（ここでは、ver3.6.0をインストールしています。）

```
pyenv install 3.6.0
pyenv rehash
```

ターミナルで以下のコマンドを実行し、「pip」（[プラグイン](http://d.hatena.ne.jp/keyword/%A5%D7%A5%E9%A5%B0%A5%A4%A5%F3)管理ツール）をインストールします。

```
sudo easy_install pip
sudo easy_install --upgrade six
sudo pip install --upgrade pip
```

ターミナルで以下のコマンドを実行し、[Python](http://d.hatena.ne.jp/keyword/Python)をpyenvでインストールした[Python](http://d.hatena.ne.jp/keyword/Python)に切り替える。（[mac](http://d.hatena.ne.jp/keyword/mac)にはデフォルトで[Python](http://d.hatena.ne.jp/keyword/Python)が入っていますが、バージョンの切り替えが簡単にできるpyenvを採用しています。）

```
echo eval "$(pyenv init -)" >> ~/.bash_profile
source ~/.bash_profile
```

ターミナルで以下のコマンドを実行することで、[Python](http://d.hatena.ne.jp/keyword/Python)のバージョンを確認できます。

```
python --version
```

ターミナルで以下のコマンドを実行し、「[OpenCV](http://d.hatena.ne.jp/keyword/OpenCV)」をインストールします。

```
pip install opencv-python
```

これで、環境構築は終了です。
