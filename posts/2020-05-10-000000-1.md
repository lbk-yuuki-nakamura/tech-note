# ■はじめに

ここでは、BitbucketにPushされたことをトリガーにして、サーバーに[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)をデプロイする方法を記載します。

Node.jsの環境やBitbucketに関しては、ある程度理解している前提で記載しますので、わからない部分は都度調べてください。

# ■手順

まずは、[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)の全量は以下です。

```javascript
var exec = require('child_process').exec
var http = require('http');
var cmd = 'cd /var/www/html/ && git pull origin master';

/*コマンド実行関数*/
function update() {
    return exec(cmd, {timeout: 90000},
        function(error, stdout, stderr) {
            if(error !== null) {
                console.log(error);
            }
        }
    )
};

http.createServer(function (req, res) {
  if(req.method == 'POST'){
        console.log("===deploy===");
        update();
  }
}).listen(3456);
```

基本的には、コピペでいいですが、以下だけ修正しないといけません。

以下は、実行するコマンドです。

cdコマンドの[ディレクト](http://d.hatena.ne.jp/keyword/%A5%C7%A5%A3%A5%EC%A5%AF%A5%C8)リを「.git」が格納されている[ディレクト](http://d.hatena.ne.jp/keyword/%A5%C7%A5%A3%A5%EC%A5%AF%A5%C8)リに指定してください。

また、pullした後に何かコマンドを実行したければ「&&」でつなげて記載してください。

```javascript
var cmd = 'cd /var/www/html/ && git pull origin master';
```

以下は、利用するポート番号を指定しています。

このポート番号は、ファイアーウォールに穴あけをしておいてください。

```javascript
}).listen(3456);
```

最後に、Bitbucketの「[リポジトリ](http://d.hatena.ne.jp/keyword/%A5%EA%A5%DD%A5%B8%A5%C8%A5%EA) -> 設定 -> Webhooks」に上記のNodeの実行URLを記載しておいてください。

例）[http://hogehoge.con:3456/](http://hogehoge.con:3456/)
