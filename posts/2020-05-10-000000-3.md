## ■はじめに

サーバーを定期的に再起動させて、予期せぬ不具合を防ぎたいと思いますよね。

でも、いちいち[VPN](http://d.hatena.ne.jp/keyword/VPN)のコンソールなどで再起動するのはめんどくさい。。。

そんな時に便利なのが、cronです。

ここでは、cronの設定を説明します。

cronの[環境変数](http://d.hatena.ne.jp/keyword/%B4%C4%B6%AD%CA%D1%BF%F4)の設定に関しては「[こちらの記事](https://developer-kuro.com/develop/?p=1212)」をご確認ください。

## ■手順

[CentOS](http://d.hatena.ne.jp/keyword/CentOS)に[SSH](http://d.hatena.ne.jp/keyword/SSH)で接続する。

rootユーザーに切り替える（rootで[SSH](http://d.hatena.ne.jp/keyword/SSH)接続した場合は不要）

以下のコマンドを実行し、cronの設定を開く

```
crontab -u root -e
```

上記の[環境変数](http://d.hatena.ne.jp/keyword/%B4%C4%B6%AD%CA%D1%BF%F4)設定のあとで、以下のように追加すると、サーバー再起動ができます。（以下は、毎日深夜0時0分にサーバー再起動する処理です。）

```
0 0 * * * reboot
```

以下がcronの全量です。

```
0 0 * * * reboot
```
