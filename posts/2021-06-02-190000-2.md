## ■はじめに

GASからSlackにメッセージを送信する方法を記載します。

Slackのワークスペースを作成しておいてください。

## ■Slackアプリの作成

[こちら](https://api.slack.com/apps)にアクセスし、Slackのワークスペースにサインインする。

※サインインしたら、Slackのワークスペースが表示されるので、別タブでもう一度「[こちら](https://api.slack.com/apps)」を開く

「Create New App」を押下し、適当なアプリ名とワークスペースを選択してアプリを作成する。

![](https://developer-kuro.com/develop/wp-content/uploads/2020/06/スクリーンショット-2020-06-23-14.33.12-300x243.png)

サイドメニューの「Incoming Webhooks」を押下する。

![](https://developer-kuro.com/develop/wp-content/uploads/2020/06/スクリーンショット-2020-06-23-14.34.35-262x300.png)

Active Incoming WebhooksをONにする。

![](https://developer-kuro.com/develop/wp-content/uploads/2020/06/スクリーンショット-2020-06-23-14.35.05-300x164.png)

画面下部の「Add New Webhook to Workspace」を押下する。

![](https://developer-kuro.com/develop/wp-content/uploads/2020/06/スクリーンショット-2020-06-23-14.35.19-300x196.png)

使用するチャンネルを選択して、「許可する」を押下する。

![](https://developer-kuro.com/develop/wp-content/uploads/2020/06/スクリーンショット-2020-06-23-14.35.26-300x236.png)

「Copy」を押下する事で、クリップボードにAPIで使用するURLがコピーされる。

![](https://developer-kuro.com/develop/wp-content/uploads/2020/06/スクリーンショット-2020-06-23-14.35.51-300x228.png)

## ■GASでメッセージを送信

ソースコードの全量は以下。

※「apiUrl」変数には、「■Slackアプリの作成」手順で取得したAPIのURLを設定する事。

```js
function sendMessage() {
  var payload  = {
    'text' : "HELLO"
  };
  var options = {'method':'post', 'contentType':'application/json', 'payload':JSON.stringify(payload)};
  var apiUrl = "https://hooks.slack.com/services/XXXXXXXXX/ZZZZZZZZZZZ/YYYYYYYYYYYYYYYYYYYYYYYY"
  UrlFetchApp.fetch(apiUrl, options);
}
```
