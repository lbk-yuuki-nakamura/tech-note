## ■はじめに

[jQuery](http://d.hatena.ne.jp/keyword/jQuery)を使用して、RestAPIを実行する方法を記載します。

[ajax](http://d.hatena.ne.jp/keyword/ajax)を利用します。

## ■手順

まずは、[ソースコード](http://d.hatena.ne.jp/keyword/%A5%BD%A1%BC%A5%B9%A5%B3%A1%BC%A5%C9)の全量は以下

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8" />
  <script src="https://code.jquery.com/jquery-3.4.1.min.js"></script>
  <script>
    $(function() {
      $('#hello').click(function() {
        $.ajax({
            url: '[APIのURL]',
            type: '[通信（GET,POST,DELETE）]',
            dataType: 'json',
            data: {"data": "a", "data2": "a"},
            timeout: 3000,
        }).done(function(data) {
            console.log(data);
        }).fail(function(XMLHttpRequest, textStatus, errorThrown) {
            console.log(XMLHttpRequest);
            console.log(textStatus);
            console.log(errorThrown);
        });
      });
    });
  </script>
</head>

<body>
  <input type="button" id="hello" value="API実行">
</body>
</html>
```

以下に関しては、それぞれ適当な環境に切り替えてください。

```
[APIのURL]
[通信（GET,POST,DELETE）]
{"data": "a", "data2": "a"}
```
