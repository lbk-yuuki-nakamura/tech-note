# DEFAULTの値を追加する方法

以下のSQL文を実行することで、デフォルト値の設定または変更を行えます。

```
ALTER TABLE テーブル名 ALTER フィールド名 SET DEFAULT デフォルト値;
```

# DEFAULTの値を削除する方法

以下のSQL文を実行することで、デフォルト値の削除を行えます。

削除後は、デフォルト値が未設定（NULL）になります。

```
ALTER TABLE テーブル名 ALTER カラム名 DROP DEFAULT;
```
