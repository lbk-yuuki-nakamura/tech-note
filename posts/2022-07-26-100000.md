# Homebrewのインストール

Homebrewは以下の公式ページからコマンドを取得して実行する。

https://brew.sh/index_ja.html

# MySQLのインストール

以下のコマンドを実行し、MySQLをインストールする。

```
brew install mysql
```

# MySQLのサーバー起動

以下のコマンドでMySQLのサーバーが起動できる。

```
mysql.server start
```

# MySQLのrootログイン

以下のコマンドで「`root`」ユーザーでMySQLにログインできる。

```
mysql -u root
```

# MySQLのバージョン確認

以下のコマンドでインストールされたMySQLのバージョンが確認できる。

```
brew info mysql
```
