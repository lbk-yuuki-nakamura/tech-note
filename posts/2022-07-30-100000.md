# 行数を取得する方法

以下の関数を使用することで、行の数字を取得できます。

```
=ROW()
```

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220722/20220722234129.png)

# 列名を取得する方法

以下の関数を使用することで、列のアルファベットを取得できます。

```
=SPLIT(ADDRESS(1,COLUMN(),4),1)
```

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220722/20220722234244.png)

# 任意の列の列名を取得する方法

以下の関数を使用することで、「`COLUMN`」の引数に記載のセルの列のアルファベットを取得できます。

```
=SPLIT(ADDRESS(1,COLUMN(B2),4),1)
```
