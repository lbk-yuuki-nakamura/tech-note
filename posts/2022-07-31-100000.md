# セル情報を取得する方法

以下の関数を実行する事で、セルの情報が取得できます。

```sh
=ADDRESS(ROW(),COLUMN(),4)
```

![](/images/2022-07-31-100000/20220722234541.png)

# 絶対参照のセル情報を取得する方法（列絶対参照）

以下の関数を実行する事で、列が絶対参照（「`$A1`」）のセルの情報が取得できます。

```sh
=ADDRESS(ROW(),COLUMN(),3)
```

![](/images/2022-07-31-100000/20220722234617.png)

# 絶対参照のセル情報を取得する方法（行絶対参照）

以下の関数を実行する事で、行が絶対参照（「`A$1`」）のセルの情報が取得できます。

```sh
=ADDRESS(ROW(),COLUMN(),2)
```

![](/images/2022-07-31-100000/20220722234700.png)

# 絶対参照のセル情報を取得する方法（列と行絶対参照）

以下の関数を実行する事で、列と行が絶対参照（「`$A$1`」）のセルの情報が取得できます。

```sh
=ADDRESS(ROW(),COLUMN(),1)
```
