# エラーに関して

コンソールに出力されるエラーは以下です。

```
Unchecked runtime.lastError: The message port closed before a response was received.
```

上記のエラーは画面表示時に出力されます。

ローカルサーバーで起動した場合に出力されました。

# エラーの原因

Google Chromeの拡張機能（chrome extension）が原因でした。

※私の場合は「Keeper」が原因でした。

調査方法は、単純に拡張機能を全てOFFにして、1つずつONに変更して確認するだけです。

# 対応方法

対応としては、特に何もしなくても良いです。

ただ、気になる方は、拡張機能をOFFにするだけです。
