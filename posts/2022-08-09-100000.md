# yumを使用してGitをインストールする方法

以下のコマンドを実行するだけです。

```sh
yum install git
```

# Sourceを使用してGitをインストールする方法

どこでも良いので、Gitのファイルをダウンロードするディレクトリへ移動します。

```sh
cd /usr/local/src/
```

サイトからGitのファイルをダウンロードします。

（以下は、バージョン2.9.5の例です）

バージョンは以下のGitHubからご確認ください。

https://github.com/git/git/tags

```sh
sudo wget https://mirrors.edge.kernel.org/pub/software/scm/git/git-2.9.5.tar.gz
```

ファイルを解凍します。

```sh
sudo tar xzvf git-2.9.5.tar.gz
```

解凍前のファイルを削除します。

```sh
sudo rm -rf git-2.9.5.tar.gz
```

Gitのディレクトリに移動します。

```sh
cd git-2.9.5/
```

以下のコマンドでインストールします。

```sh
sudo make prefix=/usr/local all
sudo make prefix=/usr/local install
```

# Gitのバージョン確認

以下のコマンドでバージョン確認ができます。

```sh
git --version
```
