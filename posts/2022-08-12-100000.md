# Stripeからトークンを取得

以下のサイトにアクセスします。

[https://dashboard.stripe.com/test/apikeys](https://dashboard.stripe.com/test/apikeys)

テスト環境がONになっている事を確認します。

※ONになっていない方は、ONにしておいてください。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220806/20220806151626.png)

「`制限付きのキーを作成`」を押下します。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220806/20220806151715.png)

キーの名前に任意の名前を入力します。（何でもいいです）

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220806/20220806151800.png)

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220806/20220806151956.png)

画面最下部の「`キーを作成`」を押下します。

「`テストキーを表示`」を押下して表示された「`トークン`」を後程利用するので、残しておいてください。

# カスタマーIDの確認

以下のダッシュボードにアクセスし、顧客を選択します。

[https://dashboard.stripe.com/test/customers](https://dashboard.stripe.com/test/customers)

顧客画面の左側に記載されている「`cus_`」から始まるものがカスタマーIDです。

※プログラム上で使用します。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220806/20220806153740.png)

# Node.jsの関数用意

以下のコマンドを実行して、Node.jsのプロジェクトにStripeをインストールします。

```sh
npm i stripe
```

以下の関数を用意します。

「`rk_test_XXXXXXXXXXXXXXXXXX`」の部分は「`Stripeからトークンを取得`」で取得したトークンに置き換えてください。

「`cus_XXXXXX`」の部分は「`カスタマーIDの確認`」で取得したカスタマーIDに置き換えてください。

```javascript
var stripe = require("stripe")("rk_test_XXXXXXXXXXXXXXXXXX");

const retrieve = async (customerId) => {
  stripe.customers.retrieve(customerId, (err, customer) => {
    if (err) {
      if (err.message === "No such customer: '" + customerId + "'") {
        console.log("カスタマーが存在しない");
      } else {
        console.log("カスタマーが存在しない以外のエラー");
        console.log(err);
      }
    } else {
      console.log("カスタマーが存在する");
    }
  });
};
```

用意した関数を以下の様に実行する事で、カスタマーの確認ができます。

```sh
retrieve("cus_XXXXXX");
```
