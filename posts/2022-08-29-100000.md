# 自動補完（オートコンプリート）とは

ログイン画面などでよくある、メールアドレスやパスワードなどが自動で入力される機能です。

# 自動補完（オートコンプリート）の無効化

ブラウザによるオートコンプリートを無効化するには以下のように「`autocomplete`」を「`off`」に設定する事で対応できます。

```
<input type="text" autocomplete="off">
```

# Chromeでの自動補完（オートコンプリート）の無効化

「自動補完（オートコンプリート）の無効化」で記載した内容では、Chromeのオートコンプリートの無効化ができませんでした。

その為、Chromeに対応する場合には「`autocomplete`」を「`new-password`」に設定する必要があります。

```
<input type="text" autocomplete="new-password">
```
