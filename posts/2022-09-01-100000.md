# はじめに

ダイアログには様々な種類があります。

通常のダイアログ（alert）と、YesかNoかを選択させるダイアログ（confirm）と、入力を受け付けるダイアログ（prompt）などがあります。

本記事では、YesかNoかを選択させるダイアログ（confirm）に関して記載します。

# 確認ダイアログ

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20220830/20220830120014.png)

確認ダイアログを表示する方法は以下です。

```JavaScript
window.confirm("確認ダイアログ");
```

以下が、サンプルボタンです。

押下する事で、確認ダイアログが表示されます。

確認ダイアログテスト

上記のサンプルボタンのソースコードは以下です。

```JavaScript
<button type="button" onclick="confirmDialog()">確認ダイアログテスト</button>

<script>
function confirmDialog() {
    window.confirm("確認ダイアログ")
}
</script>
```

# 確認ダイアログのボタン押下結果を確認

確認ダイアログのボタン押下結果を取得する方法は以下です。

```JavaScript
const result = window.confirm("確認ダイアログ");
```

以下が、サンプルボタンです。

押下する事で、確認ダイアログが表示されます。

確認ダイアログのボタン押下で、結果をアラートダイアログに表示しています。

確認ダイアログテスト

上記のサンプルボタンのソースコードは以下です。

```JavaScript
<button type="button" onclick="confirmDialogCheck()">確認ダイアログテスト</button>

<script>
function confirmDialogCheck() {
    const result = window.confirm("確認ダイアログ");
    window.alert(result);
}
</script>
```
