# はじめに

例外処理を記載したが、エラーが発生しても実行したい処理があります。

その場合の対応として、finally文を使用して処理を記載する事ができます。

# 例外発生時にも実行される処理

「`finally`」を記載する事で、その内部の処理が例外発生に関わらず必ず実行されます。

```javascript
try {
    console.log("Hello" + world);
} catch (e) {
    console.log(e.message);
} finally {
    console.log("例外が発生しても、発生しなくても実行されます。");
}
```
