# 分岐処理とは

信号が青の場合は、進む。

信号が赤の場合は、止まる。

といったように、「`〜の場合は、〜する`」という分岐する処理のことを、分岐処理と言います。

# 条件分岐

以下のような「`switch文`」の記述を行うことで、条件分岐を行うことができます。

```
switch (変数){
  case 条件:
    条件に一致する場合処理を実行
    break;
}
```

一例として、タイプがいくつか？という分岐を以下に記載します。

```
switch (type){
  case 1:
    console.log("タイプが１です。");
    break;
}
```

# 条件に当てはまらない場合

以下のような「`switch文`」の記述を行うことで、条件分岐で、条件に当てはまらない場合の処理を行うことができます。

```
switch (変数){
  case 条件:
    条件に一致する場合処理を実行
    break;
  default:
    条件に一致しない場合の処理を実行
}
```

一例として、タイプが１ではない場合を以下に記載します。

```
var type = 1;
switch (type){
  case 1:
    console.log("タイプが１です。");
    break;
  default:
    console.log("タイプが１ではありません。");
}
```

# 複数の条件分岐

以下のような「`switch文`」の記述を行うことで、複数の条件分岐を行うことができます。

```
switch (変数){
  case 条件:
    条件に一致する場合処理を実行
    break;
  case 条件1:
    条件1に一致する場合処理を実行
    break;
  default:
    全ての条件に一致しない場合の処理を実行
}
```

以下に使用例を記載します。

```
var type = 1;
switch (type){
  case 1:
    console.log("タイプが１です。");
    break;
  case 2:
    console.log("タイプが２です。");
    break;
  default:
    console.log("タイプが１でも２でもありません。");
}
```
