# エラーの内容

「`One or more plugins require a higher Android SDK version`」のエラーは、簡単に言うと、「`コンパイルで使用しているAndroid SDKバージョンが古いから新しくしてね。`」と言うエラーです。

Flutterのバージョンを上げた際などに発生する事があります。

# 対応方法

「`One or more plugins require a higher Android SDK version`」のエラーが発生した場合、少し下のエラーメッセージに、以下のようなエラーが表示されていると思います。

```
android {
  compileSdkVersion 31
  ...
}
```

上記の場合は、「`compileSdkVersion`」を「`31`」に上げればいいです。

VSCodeを使用している場合には、「command + shift + f」で検索を行い、「`compileSdkVersion`」を探します。

「`build.gradle`」にあると思いますので、該当箇所を「`31`」に上げて再度ビルドを行えば完了です。
