# switch文中のreturnの挙動

以下の様なソースコードをPlaygroundで作成して実行します。

```javascript
class aaa {
    func hoge() {
        let tp = 1
        let hoge = 1

        switch tp {
        case 1:
            print("===========1")
            if hoge == 1 {
                print("===========2")
                return
            }
            print("===========3")
        default:
            print("===========def")
        }

        print("===========4")
    }
}

var h = aaa()
h.hoge()
```

コンソールにて結果を見てみると、以下の出力がされていました。

つまり、switch中のreturnでも関数の処理が中断して終了されている事がわかりました。

```sh
===========1
===========2
```
