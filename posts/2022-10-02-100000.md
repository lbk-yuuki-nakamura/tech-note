Let’s Encrypt

# エラー発生

```sh
/usr/bin/certbot renew
```

# 対応方法

nginxを停止します。

```sh
systemctl stop nginx
```

証明書を更新します。

```sh
/usr/bin/certbot renew
```

Apatchを停止します。

```sh
systemctl stop httpd
```

nginxを再起動します。

```sh
systemctl start nginx
```

これで、証明書の更新が正常に完了です。
