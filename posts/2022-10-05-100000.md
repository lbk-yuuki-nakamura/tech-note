# 現在時刻取得

以下のように「DateTime」を使用して時刻の取得を取得します。

```
DateTime.now();
```

# 現在の年月日時分秒をバラバラに取得する方法

現在時刻取得から「年」「月」「日」「時」「分」「秒」をバラバラに取得する方法は以下です。

```
var now = DateTime.now();
print(now.year); // 年
print(now.month); // 月
print(now.day); // 日
print(now.hour); // 時
print(now.minute); // 分
print(now.second); // 秒
```
