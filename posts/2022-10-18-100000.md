# unicode

unicodeとは、「`あ`」という文字は「`\u3042`」と記載する事ができます。

この「`\u3042`」がunicode（ユニコード）です。

# unicodeの文字列取得API

本記事の例として、以下のAPIを例とします。

このAPIを実行することで、文字列が返却されます。（各自のAPIに置き換えてください）

```
curl -X GET "https://example.com/api"
```

# 日本語で取得する方法

以下のコマンドを実行し、Homebrewで「`jq`」のインストールを行います。

```
brew install jq
```

以下の様にcurlを実行することで、日本語で文字列が表示されます。

```
curl -X GET "https://example.com/api" | jq .
```
