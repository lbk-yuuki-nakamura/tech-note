# GASでスラッシュコマンド実行時の受け口を作成

「Google Apps Script」を開き、以下を貼り付ける。

```JavaScript
function doPost(e) {
  const param = e.parameter;
  const command = param.command
  const userId = param.user_id

  switch (command) {
    case '/test':
      let response = { text: 'テストメッセージ ' + userId + " からスラッシュコマンドが実行された" };
      return ContentService.createTextOutput(JSON.stringify(response)).setMimeType(ContentService.MimeType.JSON);
    default:
      return ContentService.createTextOutput(JSON.stringify(e));
  }
}
```

# スラッシュコマンドの作成

以下にアクセスし、任意のSlackのサインインを行う。

https://api.slack.com/apps

スラッシュコマンドの作成を行いたいSlack Appを押下する。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017120303.png)

「`Slash Commands`」を押下する。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017183526.png)

「`Create New Command`」を押下する。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017183559.png)

それぞれの入力項目に任意の値を入力する。

Command: コマンド

Request URL: 「`GASでスラッシュコマンド実行時の受け口を作成`」で生成したウェブアプリのURL

Short Description: コマンドの説明

Usage Hint: コマンドのヒント

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017183628.png)

「`Save`」を押下する。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017183810.png)

以下の様にコマンドが追加されていれば成功です。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017183837.png)

ヘッダー上部に表示される「`reinstall your app`」を押下することで、Slack Appの再インストールが行われ、コマンドが使用できる様になります。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017183909.png)

上記のヘッダーが表示されない場合には、「`OAuth & Oermissions`」メニューの「`OAuth Tokens for Your Workspace`」の「`Reinstall to Workspace`」を押下してください。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017120858.png)

# スラッシュコマンドの使用方法

Slackにて、自分のDMを開きます。（Slack Appが追加されているチャンネルでも大丈夫です。）

メッセージ欄に「`/test`」（使用したいコマンド）と入力します。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017184204.png)

出てきたポップアップから、使用したいコマンドを選択します。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017184238.png)

以下の様にメッセージが表示されれば成功です。

![](https://cdn-ak.f.st-hatena.com/images/fotolife/r/reigle/20221017/20221017184308.png)
