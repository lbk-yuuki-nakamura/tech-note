# はじめに

Firebaseの公式サイトから、手順に沿ってFirebaseの組み込みを実施してください。

Firebaseの管理画面などから、アカウント作成を行なっておいてください。

# 手順

「`pubspec.yaml`」に以下を追加します。

```
dependencies:
  ~~~省略~~~
  firebase_core: ^1.3.0
  firebase_database: ^9.0.19
  firebase_auth: ^1.4.1
  ~~~省略~~~
```

以下のクラスを作成します。

「`email: "sample@example.com", password: "Sample111"`」のログイン情報は自身で作成したログイン情報に変更してください。

「`authenticationSample`」メソッドを実行することで、ログインは完了です。

```
import 'dart:convert';
import 'package:firebase_auth/firebase_auth.dart';

class FirebaseSample {
  FirebaseSample();

  void authenticationSample() async {
    try {
      await FirebaseAuth.instance.signInWithEmailAndPassword(email: "sample@example.com", password: "Sample111");
    } catch (e) {
      print('Error : $e');
    }
  }
}
```
