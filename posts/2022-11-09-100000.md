# goenvのインストール

以下のコマンドを実行して、「`goenv`」のインストールを行う。

```sh
brew install goenv
```

上記のインストールが完了したら、下記を実行する。

```sh
vi ~/.zshrc
```

上記にて、開いた「`.zshrc`」を「`i`」を押下して編集モードに変更。

以下を最下部にコピペで貼り付ける。

```sh
# goenv
export GOENV_ROOT="$HOME/.goenv"
export PATH="$GOENV_ROOT/bin:$PATH"
eval "$(goenv init -)"
```

以下を実行し、変更を適応する。

```sh
source ~/.zshrc
```

以下を実行して、goenvのバージョン情報が返ってきたら成功です。

```sh
goenv -v
```

上記のレスポンスは以下の様な形式で返却されます。

```sh
goenv 2.0.2
```
