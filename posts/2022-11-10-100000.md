# Go言語のインストール方法

以下のコマンドでインストール可能なバージョンの一覧を検索します。

```sh
goenv install -l
```

「`1.19.2`」をインストールする場合には、以下の様にインストールコマンドを実行します。

```sh
goenv install 1.19.2
```

上記のインストール完了後、以下の様に、グローバルにインストールしたバージョンを設定します。

```sh
goenv global 1.19.2
```

以下のコマンドを実行して、バージョンのレスポンスが返却されれば成功です。

```sh
go version
```

上記のレスポンスは以下の様な形式で返却されます。

```sh
go version go1.19.2 darwin/arm64
```
