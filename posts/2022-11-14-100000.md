# 初期値なし変数定義

「`var 変数名 型`」の様な形で変数の定義が可能です。

一例としては、以下です。

```go
var str string
```

# 初期値あり変数

「`var 変数名 型 = 値`」の様な形で変数の定義が可能です。

一例としては、以下です。

```go
var str string = "変数の中身"
```

「`型`」に関しては、「`値`」から推測する事が可能で、「`var 変数名 = 値`」のように「`型`」を省略して書くことも可能です。

```go
var str = "変数の中身"
```

「`変数名 := 値`」の様に、「`var`」を省略することも可能です。

```go
str := "変数の中身"
```
