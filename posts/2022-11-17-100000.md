# 定数定義

以下の様な形でiotaの定義を行うことで、連番の定数定義が可能です。

iotaを設定している箇所が０で以降の定数に順番に1,2...と数値が設定されます。

```
const (
    Zero = iota  // 0
    One // 1
    Two // 2
)
```
