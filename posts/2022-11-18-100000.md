# コメントとは

「コメント」はちょっとしたメモを書いたり、処理の説明を記述しておいたり、今は使用しない処理を一旦無視するようにしておいたり、といった使い方をする。

「コメント」の部分はプログラムとして実行される事はない。

# 単一行のコメント

単一行のコメントは「`//`」から始まり、改行までの間がコメントになります。

```
// コメント
```

# 複数行のコメント

複数行のコメントは「`/*`」から、「`*/`」までの間がコメントになります。

```
/*
コメント1行目
コメント2行目
*/
```

# コメントアウト

プログラミングをしている中で、「一旦この行の処理を行いたくない」と思う時がある。

その時には、上記のコメントを記載する事で処理を行わないようにする事ができる。

これを「コメントアウト」という。

単一行のコメントアウト

```
// println("Hello")
```

複数行のコメントアウト

```
/*
println("Hello")
println("World")
*/
```
