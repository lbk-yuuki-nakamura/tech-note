# while文と同様のループ処理

Go言語には「while文」は存在しません。

しかし、while文と同様の操作は「for文」で行う事ができます。

以下の例のように、forの後に任意の条件式を記載することで、その条件がtrueの間はループが実行されます。

以下の例では、1が10未満の間はループされます。

```JavaScript
i := 0

for i < 10 {
    fmt.Println(i)
    i++
}
```
