# foreach文と同様のループ処理

Go言語には「foreach文」は存在しません。

しかし、foreach文と同様の操作は「for文」で行う事ができます。

以下の例では、文字列配列型のデータをループ処理して、indexにインデックス番号、valueに配列の中の値が入る様に処理しています。

```JavaScript
var strArray = []string{"Str1", "Str2", "Str3", "Str4"}
for index, value := range strArray {
  println(index)
  println(value)
}
```
