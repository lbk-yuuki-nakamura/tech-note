# コマンドの実行方法

Macの場合には、「`ターミナル`」アプリを起動することで、コマンドを実行する事ができます。

LinuxやCentOSなどの場合は、それぞれのCUIにて実行する事ができます。

# mvコマンド

mvコマンドは、ファイルやディレクトリを移動したり、リネームしたりするコマンドです。

# ファイルをディレクトリ移動

以下のコマンドを実行することで、「`ディレクトリ名`」へファイルを移動する事ができます。

```sh
mv ファイル名 ディレクトリ名
```

例

```sh
mv sample.txt dir_name
```

# ディレクトリを移動

以下のコマンドを実行することで、「`ディレクトリ名`」へディレクトリごと移動する事ができます。

```sh
mv 移動したいディレクトリ名 ディレクトリ名
```

例

```sh
mv sample_dir/ dir_name
```

# ファイル名変更

以下のコマンドを実行することで、ファイル名を変更する事ができます。

```sh
mv 変更前ファイル名 変更後ファイル名
```

例

```sh
mv before.txt after.txt
```
