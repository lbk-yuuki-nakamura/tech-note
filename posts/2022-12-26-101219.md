# 説明

CollectionViewの下ではなく、セルがスクロールした後の一番したに余白を設定する方法を記載します。

# 実装

以下のソースコードは、CollectionViewのインスタンスが「`collectionView`」という前提です。
40pxの余白を設定しています。

```JavaScript
collectionView.contenInset = UIEdgeInsets(top: 0, left: 0, bottom: 40, right: 0)
```
