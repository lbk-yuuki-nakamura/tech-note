# KnexのUpdateの方法

以下のようにUpdateを行うことができます。

```JavaScript
export const setData = async (
  knex: Knex,
  id: number,
  name: string,
) => {
  await knex("table")
    .update({name: name})
    .where({
      id: id,
    })
};

setData(knex, 1, "hoge");
```

# オブジェクト型を使用して一括でUpdateする方法

以下のようにオブジェクト型を使用して一括でUpdateを行うことができます。

```JavaScript
export const setData = async (
  knex: Knex,
  data: UpdateData,
) => {
  await knex("table")
    .update(data)
    .where({
      id: data.id,
    })
};

setData(knex, {id: 1, name: "hoge"});
```
