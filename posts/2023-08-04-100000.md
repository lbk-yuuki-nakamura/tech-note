# エラーの発生箇所

以下のソースが実行された際に、ChromeのDeveloperToolsにエラーが表示されます。

```JavaScript
window.location.href = "app://aaa"
```

# エラーの意味

```sh
Failed to launch 'app://aaa' because the scheme does not have a registered handler.
```

ブラウザが "app://" スキームに対応する登録済みのハンドラを見つけることができなかったことを意味しています。

つまり、このスキームに対応する外部アプリケーションがデバイスにインストールされていないか、ブラウザがそれをサポートしていない可能性があります。

# 対処方法

該当のアプリが入っているモバイルアプリで該当処理を実行することで、解決します。
