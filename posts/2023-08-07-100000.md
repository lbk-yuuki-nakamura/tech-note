# 期待値

以下のようなオブジェクトを

```JavaScript
{ key1: "aaa", hoge: "bbb" }
```

以下のようにvalueを空文字にしたい

```JavaScript
{ key1: "", hoge: "" }
```

# 実装

以下のように実装することで、valueが空のオブジェクトにできます。

```JavaScript
const obj = { key1: "aaa", hoge: "bbb" }
const newObj = Object.fromEntries(
  Object.keys(obj).map((key) => [key, '']),
);

console.log(newObj);
```
