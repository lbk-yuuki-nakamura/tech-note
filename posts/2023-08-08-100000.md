# 実装方法

以下のように実装することで

```JavaScript
const map = new Map()
map.set("a", "あああ");
map.set("b", "いいい");
map.set("c", "ううう");

const obj = Object.fromEntries(map.entries());

console.log(obj);
```

以下のようなオブジェクトが生成されます。

```JavaScript
{ a: "あああ", b: "いいい", c: "ううう" }
```
