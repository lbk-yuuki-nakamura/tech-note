# マークアップ言語とは？

マークアップ言語とは、テキストを加工して表示するための言語の一つです。

この言語はテキストの意味や構造を示すタグや注釈を付加して、特定の表示や動作をさせることができます。

# 主なマークアップ言語の例

1. HTML (Hyper Text Markup Language)

- Webページを作成するための言語。

- タグを使って、テキストや画像、リンクなどの要素をページ上に配置します。

2. XML (eXtensible Markup Language)

- データを構造的に記述するための言語。

- 人間も機械も読みやすい形式でデータを交換できます。

3. Markdown

- プレーンテキストをHTMLに変換するための軽量マークアップ言語。

- 簡単な記法で美しくフォーマットされた文書を作成できます。

# なぜマークアップ言語を使用するのか？

- 整理・構造化: テキストに構造や意味を追加して、内容の理解を容易にします。

- 表現力の拡張: シンプルなテキストだけでは表現しきれない情報や装飾を追加することができます。

- 多目的性: 同じテキストに対して、異なるマークアップを適用することで、異なる用途や表示形式に対応できます。
