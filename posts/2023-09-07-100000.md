# JavaScriptで日付を特定の日時に設定する方法

JavaScriptの `Date` オブジェクトは、日付と時間の操作に非常に便利なメソッドを提供しています。

特定の日付や時間にオブジェクトを設定する必要がある場合、いくつかの簡単なステップでこれを達成できます。

# 現在の日付を0時0分0秒に設定する

`Date` オブジェクトを作成すると、デフォルトでは現在の日付と時間が設定されます。

以下の方法で、この日付を当日の0時0分0秒に変更できます。

```JavaScript
const date = new Date();
date.setHours(0, 0, 0, 0);
console.log(date);
```

# 日付を1日の0時0分0秒に設定する

特定の月の1日に日付を設定する場合、さらに `setDate()` メソッドを使用できます。

```JavaScript
const date = new Date();
date.setDate(1);
date.setHours(0, 0, 0, 0);
console.log(date);
```

この方法で、Date オブジェクトは特定の月の1日の0時0分0秒を正確に示すようになります。

まとめると、JavaScriptの `Date` オブジェクトは、日付と時間を操作するための強力なツールセットを提供しています。

上記の方法を使用することで、特定の日時に日付を簡単に設定できます。
