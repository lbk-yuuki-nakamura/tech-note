# JavaScript で配列の現在の値と次の値を取得する方法

JavaScript で配列をループするとき、特定のシチュエーションで現在の値だけでなく、次の値も同時に取得したい場合があります。

この記事では、その方法を簡単に説明します。

# 基本的な方法

配列をループする基本的な方法は `for` ループを使用することです。

以下の例では、文字列の配列をループして、現在の値と次の値を取得します。

```JavaScript
let arr = ['a', 'b', 'c', 'd'];

for (let i = 0; i < arr.length - 1; i++) {
  let current = arr[i];
  let next = arr[i + 1];

  console.log('現在の値:', current);
  console.log('次の値:', next);
}
```

このコードは、配列の最後の要素を除くすべての要素に対してループを実行します。

これは、最後の要素の「次の値」が存在しないためです。

# 注意点

上記の方法では、配列の最後の要素の次の値は取得されません。

最後の要素でも次の値を取得したい場合（例えば、配列が環状になっていて最後の要素の次が最初の要素になる場合など）は、適切なロジックを追加する必要があります。
