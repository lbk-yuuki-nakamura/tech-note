# Tailwind CSSでの`white-space: pre-line`の使用方法

Tailwind CSSはユーティリティファーストなCSSフレームワークであり、多くの便利なクラスを提供しています。

中でも、テキストのホワイトスペースの扱いを制御するための`whitespace`ユーティリティは、テキストの表示を柔軟に制御する際に役立ちます。

# `whitespace-pre-line`の基本的な使用方法

Tailwind CSS 2.x以降では、`whitespace-pre-line`というクラスがデフォルトで提供されています。

このクラスを使用することで、CSSの`white-space: pre-line;`と同等の効果を得ることができます。

```

  これはテキストです。
  改行されます。

```

上記のコードのように、`whitespace-pre-line`クラスをHTML要素に適用することで、テキスト内の連続するホワイトスペースや改行がそのまま反映されます。

# まとめ

Tailwind CSSを使用すると、多くのデザインやレイアウトのニーズに応じて、簡単にスタイルを適用することができます。

`whitespace-pre-line`は、テキストの表示を制御するためのユーティリティの一つとして、特に役立つでしょう。

このユーティリティを使用して、より柔軟なテキスト表示を実現してみてください。
