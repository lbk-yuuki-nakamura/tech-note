# Turborepoのキャッシュクリアガイド

TurborepoはNode.jsのエコシステムにおいて重要な役割を果たすツールです。

効率的なモノレポ管理のために、キャッシュ機能が大いに役立ちます。

しかし時には、このキャッシュをクリアする必要があることもあります。

この記事では、Turborepoのキャッシュをクリアする方法について詳しく説明します。

# ローカルキャッシュのクリア

ローカルでのキャッシュクリアは比較的簡単です。

以下の手順に従ってください。

# ステップ 1: キャッシュの場所を特定

Turborepoは通常、プロジェクトのルートにある`.turbo`フォルダにキャッシュを保存します。

# ステップ 2: キャッシュディレクトリの削除

プロジェクトのルートディレクトリに移動し、次のコマンドを実行してキャッシュを削除します。

```sh
rm -rf .turbo
```

# リモートキャッシュのクリア

リモートキャッシュを使用している場合、プラットフォームによってクリア方法が異なります。

例えば、Vercelを使用している場合は、VercelのダッシュボードやCLIを通じてキャッシュを管理できます。

# 注意点

- キャッシュをクリアすると、次回のビルドが遅くなることがあります。

- キャッシュの問題がビルドに影響を与えている場合のみ、クリアを検討してください。

- チームのベストプラクティスに従い、必要に応じてドキュメントを参照してください。

このガイドが、Turborepoを使用する際の効率的なワークフローに貢献することを願っています。
