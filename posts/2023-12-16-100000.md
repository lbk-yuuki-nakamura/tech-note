# Tailwind CSSを使用したテキスト装飾の方法

Tailwind CSSを活用すると、HTML要素に対して簡単にテキスト装飾を適用することができます。
ここでは、Tailwind CSSで利用できる主なテキスト装飾クラスについて説明します。

## アンダーライン (`underline`)

テキストに下線を追加するには、`underline` クラスを使用します。

```html

これは下線付きのテキストです。

```

## ラインスルー (`line-through`)

テキストに取り消し線を追加するには、`line-through` クラスを使用します。

```html

これは取り消し線付きのテキストです。

```

## オーバーライン (`overline`)

テキストに上線を追加するには、`overline` クラスを使用します。

```html

これは上線付きのテキストです。

```

## テキスト装飾なし (`no-underline`)

テキストからすべての装飾を削除するには、`no-underline` クラスを使用します。

```html

これは装飾なしのテキストです。

```

これらのクラスを使って、テキストの見た目を簡単にカスタマイズできます。
Tailwind CSSのバージョンによっては、これらのクラスがデフォルトで利用可能でない場合があるので、設定ファイルで有効化する必要があるかもしれません。
