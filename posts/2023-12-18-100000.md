# Tailwind CSSでカスタムフォントを設定する方法

Tailwind CSSを使用する際、カスタムフォントを適用する方法は簡単です。
この記事では、`tailwind.config.js`ファイルに新しいフォントを追加し、HTMLでそのフォントを使用する手順を説明します。

## ステップ1: カスタムフォントを設定ファイルに追加

最初に、`tailwind.config.js`ファイルを開き、`extend`セクション内に新しいフォントファミリーを追加します。
以下に例を示します。

```JavaScript
module.exports = {
  theme: {
    extend: {
      fontFamily: {
        myfont: ['MyFont', 'sans-serif'],
      },
    },
  },
};
```

このコードでは、新しいフォントファミリー`myfont`を定義し、`MyFont`をそのメインフォントとして設定しています。
フォールバックとして`'sans-serif'`フォントを指定しています。
